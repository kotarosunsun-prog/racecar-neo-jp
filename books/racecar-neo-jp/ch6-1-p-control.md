4-2 で、センサで結果を確かめ、ずれを直しながら命令を決める「クローズドループ（フィードバック）」を学びました。この回では、その中でいちばん基本になる**比例制御**を学びます。「ずれが大きいほど強く、小さいほど弱く直す」という、とても単純な考え方です。この章のライントレースも、壁沿い走行も、すべてここから始まります。

## ① この回でできるようになること

1. 目標・測った値・ずれ（誤差）の関係を説明できる
2. オン・オフ制御と比例制御の違いを説明できる
3. 比例ゲイン KP の大きさによって、ふるまいがどう変わるかを説明できる
4. LIDAR で測った距離を使って、壁の手前で止まるプログラムを書ける

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |
|---|---|---|
| Target / Setpoint | 目標値 | こうなってほしい、という値。この回では「壁まで 50 cm」 |
| Measurement | 測定値 | センサで測った、今の値 |
| Error | 誤差（ずれ） | 測定値と目標値の差 |
| On-off control | オン・オフ制御 | ずれの向きだけを見て、全開か全開の逆か（または止めるか）を決めるやり方 |
| Proportional control | 比例制御（P 制御） | ずれに比例した大きさの命令を出すやり方 |
| Gain | ゲイン | ずれに何倍をかけて命令にするか、の数。比例制御では KP と書く |
| Saturation | 飽和（ほうわ） | 命令が上限（−1〜1）に達して、それ以上大きくならないこと |
| Overshoot | 行き過ぎ（オーバーシュート） | 目標を通りこしてしまうこと |

## ③ 本文

### 例：壁の手前 50 cm で止まる

車を前に進ませて、正面の壁の手前 50 cm でぴったり止めたいとします。LIDAR で正面の壁までの距離 `front` を毎コマ測れるので（5-3）、次のような**ずれ**が計算できます。

$$
\text{error} = \text{front} - \text{TARGET}
$$

`TARGET` は目標の 50 cm です。`error` がプラスなら「まだ手前にいる（もっと進む）」、マイナスなら「行き過ぎた（下がる）」、0 なら「ちょうど目標」です。問題は、この `error` から、`speed` をどう決めるかです。

### オン・オフ制御：全開か、全開の逆か

いちばん単純なのは、ずれの**向きだけ**を見るやり方です。

```python
if error > 0:
    speed = 1.0     # 遠ければ、全開で前へ
else:
    speed = -1.0    # 近ければ、全開で後ろへ
```

これを**オン・オフ制御**といいます。エアコンやこたつが「寒ければ全開、暑ければ止める」をくり返すのと同じしくみです。

ところが、車ではうまくいきません。車は急には止まれないので、目標の 50 cm で後ろ向きに切りかえても、しばらく前に進んで行き過ぎます。今度は全開で下がり、また行き過ぎて…と、目標のまわりを行ったり来たりし続けます（図2の赤い線）。

### 比例制御：ずれに比例した強さで

そこで、**ずれに比例した**速さにします。

$$
\text{speed} = K_P \times \text{error}
$$

$K_P$（ケー・ピー）は**比例ゲイン**で、「ずれ 1 cm あたり、speed をいくつにするか」を決める数です。これを**比例制御**（P 制御、P は Proportional の頭文字）といいます。

- 遠く（ずれが大きい）ときは、強く進む
- 目標に近づく（ずれが小さくなる）ほど、弱く進む
- 目標ちょうど（ずれ 0）なら、止まる
- 行き過ぎた（ずれがマイナス）なら、そのぶんだけ弱く下がる

![比例制御の流れ。目標（TARGET = 50 cm）と、LIDAR で測った距離 front の差からずれ e を作り、KP をかけて speed にして車に送る。車が動くと LIDAR の測る距離が変わり、また差をとる、を毎コマくり返す。error = front − TARGET、speed = KP × error（−1〜1 に収める）](/images/racecar-neo-jp/6-1/fig1-loop.png)
*図1　比例制御の流れ*

`speed` は −1〜1 の範囲でなければならないので、計算した値が範囲をこえたら、はしに押さえこみます（3-2 のクランプ）。壁から遠いうちは、`KP × error` が 1 をこえて、ずっと全開です。このように、命令が上限に張りついた状態を**飽和**といいます。

### KP の大きさで、ふるまいが変わる

![壁までの距離の時間変化を、説明用の簡単なモデルで計算したグラフ。300 cm から出発し、はじめはどのやり方も全開なので同じ線を描く。オン・オフ制御（赤）は目標 50 cm のまわりで上下にゆれ続ける。KP = 0.005（オレンジ）は目標に近づくにつれてゆっくりになり、6秒たってもまだ少し手前。KP = 0.02（緑）は少しだけ行き過ぎてから 50 cm に落ち着く。KP = 0.1（青）は 35 cm ほどまで大きく行き過ぎ、少しゆれてから落ち着く](/images/racecar-neo-jp/6-1/fig2-stop.png)
*図2　オン・オフ制御と、KP をかえた比例制御（説明用の簡単なモデル）*

- **KP が小さすぎる**（0.005）：ずれが小さくなると、命令もすぐ小さくなるので、目標にゆっくりしか近づけない
- **KP がちょうどよい**（0.02）：少しだけ行き過ぎて、すぐに落ち着く
- **KP が大きすぎる**（0.1）：目標のかなり近くまで全開のままなので、大きく行き過ぎて、ゆれてから落ち着く。KP をもっと大きくすると、オン・オフ制御に近づいていく

KP は、実際に走らせながら調整する数です。はじめは小さめから始め、ゆっくりすぎるなら大きくし、行き過ぎやゆれが大きいなら小さくします。

### やってみよう：壁の手前で止まる

```python:stop_at_wall.py
"""
stop_at_wall.py
正面の壁までの距離を LIDAR で測り、壁の手前 TARGET cm で止まる（比例制御）。
"""

import sys

sys.path.insert(1, "../../library")
import racecar_core
import racecar_utils as rc_utils

rc = racecar_core.create_racecar()

TARGET = 50.0    # 止まりたい、壁までの距離（cm）
KP = 0.02        # 比例ゲイン：ずれ 1 cm あたり、speed をいくつにするか


def start():
    rc.drive.stop()
    rc.set_update_slow_time(0.5)
    print(f">> 壁の手前 {TARGET:.0f} cm で止まります")


def update():
    scan = rc.lidar.get_samples()
    _, front = rc_utils.get_lidar_closest_point(scan, (350, 10))   # 正面 ±10° でいちばん近い距離

    error = front - TARGET                        # ずれ：あと何 cm 進めばよいか
    speed = rc_utils.clamp(KP * error, -1.0, 1.0)  # ずれに比例した速さ（-1〜1 に収める）
    rc.drive.set_speed_angle(speed, 0.0)


def update_slow():
    scan = rc.lidar.get_samples()
    _, front = rc_utils.get_lidar_closest_point(scan, (350, 10))
    print(f"正面の壁まで {front:6.1f} cm")


if __name__ == "__main__":
    rc.set_start_update(start, update, update_slow)
    rc.go()
```

`rc_utils.clamp(値, 下限, 上限)` は、値を下限と上限の間に押さえこむ関数です。シミュレータでは、壁の正面に車を置けるレベル（**Sandbox Environments** の **LIDAR Sandbox** など）で、手動運転で壁に向けてから Enter を押して試します。

説明用の簡単なモデルで、壁の 300 cm 手前から動かすと、次のように表示されました。

```text
>> 壁の手前 50 cm で止まります
正面の壁まで  299.3 cm
正面の壁まで  259.4 cm
正面の壁まで  188.5 cm
正面の壁まで  114.2 cm

正面の壁まで   40.0 cm
正面の壁まで   49.7 cm
正面の壁まで   51.7 cm
正面の壁まで   50.0 cm
```

`KP` を 0.005 や 0.1 に変えて、止まり方がどう変わるか比べてみましょう。

### 比例制御の弱点：目標にぴったり届かないことがある

比例制御では、目標に近づくほど命令が小さくなります。実機の車は、`speed` が小さすぎると、タイヤの摩擦に負けて動き出せません。すると、目標の少し手前で止まってしまい、ずれが残ります。このずれを消す方法は、6-11 の I（積分）で学びます。

## ④ 数式・コード

### KP の最初の決め方

「ずれがこれだけあったら全開にしたい」という大きさ $e_{\text{full}}$ を決めると、KP の最初の目安が求まります。

$$
K_P = \frac{1}{e_{\text{full}}}
$$

たとえば、「ずれが 50 cm 以上なら全開」とするなら、$K_P = \frac{1}{50} = 0.02$ です。`stop_at_wall.py` の 0.02 は、こうして決めました。ここから、走らせながら調整していきます。

### KP の単位

`speed` には単位がありません（−1〜1 の数）。ずれ `error` は cm です。そのため、$K_P$ の単位は「1/cm」です。ずれを m で測るように変えたら、同じふるまいにするには、$K_P$ を 100 倍にしなければなりません。KP の値は、**ずれを何の単位で測っているか**とセットで考えます。

### remap_range を使う書き方

`rc_utils.remap_range()` を使うと、「距離がこの範囲なら、speed をこの範囲に」と書けます。

```python
speed = rc_utils.remap_range(front, TARGET, TARGET + 50, 0.0, 1.0, True)
```

これは「`front` が TARGET なら 0、TARGET + 50 なら 1」になるように、まっすぐな関係でつないだもので、$K_P = 0.02$ の比例制御と同じです。最後の `True` は、結果を 0〜1 の範囲に押さえこむ（飽和させる）という意味です。この書き方だと、下限が 0 なので、行き過ぎても後ろには下がりません。

## ⑤ つまずきポイント

### 壁に向かって、全開で突っこんでいく

ずれの符号が逆になっていないか確かめましょう。`error = TARGET - front` と書くと、遠いほどマイナスの命令になり、後ろに下がっていきます（または、行き過ぎたときに前に進みます）。「遠いときに、プラスの `speed` になるか」を、紙の上で確かめてから走らせます。

### 壁が見えないのに、全開で走り出す

`get_lidar_closest_point()` は、窓の中に 0.0（データなし）しかないと、距離としてとても大きな値（$10^6$）を返します。すると、ずれがとても大きくなり、全開で走り出します。遠くに壁がないところでは、`front` が大きすぎるときは止まる、などの安全策を加えましょう。

### 目標の少し手前で止まったまま、動かない

「比例制御の弱点」で書いたように、命令が小さすぎて、摩擦に負けています。KP を少し大きくすると改善しますが、大きくしすぎると行き過ぎます。根本的な対策は 6-11 で学びます。

## ⑥ 確認問題

**問1**　`TARGET = 50`、`KP = 0.02` のとき、正面の壁までの距離が 80 cm、40 cm、250 cm のときの `speed` はそれぞれいくつですか（−1〜1 に押さえこむ）。

:::details 答え
80 cm：$0.02 \times (80 - 50) = 0.6$
40 cm：$0.02 \times (40 - 50) = -0.2$（少し下がる）
250 cm：$0.02 \times 200 = 4$ ですが、上限の 1 に押さえこまれて $1.0$（全開）
:::

**問2**　オン・オフ制御で、車が目標のまわりを行ったり来たりし続けるのはなぜですか。

:::details 答え
車は急には止まれないので、目標で命令を切りかえても、勢いで行き過ぎてしまうからです。オン・オフ制御は、目標のすぐ近くでも全開の命令を出すので、毎回大きく行き過ぎます。
:::

**問3**　「ずれが 25 cm 以上なら全開」にしたいとき、KP の最初の目安はいくつですか。そのとき、図2の KP = 0.02 と比べて、止まり方はどう変わると考えられますか。

:::details 答え
$K_P = \frac{1}{25} = 0.04$ です。目標のより近くまで全開で進むので、速く近づけますが、行き過ぎが大きくなりやすくなります。
:::
