実機の RACECAR は、LiPo（リチウムポリマー）バッテリーで走ります。LiPo は、電圧を下げすぎる（使いすぎる）と傷んでしまい、ふくらんだり、充電できなくなったりします。実機では、`rc.physics.get_battery_voltage()` でバッテリーの電圧〔V〕を、`rc.physics.get_battery_current()` で電流〔A〕を読めます（シミュレータにはセンサがないので、どちらもいつも 0.0 です）。この回では、それを使って、走りながらバッテリーの電圧を見はり、下がってきたら「注意」、さらに下がったら「止まる」を決めるプログラムを作ります。

## ① この回でできるようになること

1. LiPo の電圧の目安（満充電・公称・下げてはいけない電圧）を、1 セルあたりとバッテリー全体で言える
2. 走っているとき電圧が一瞬下がる理由を、オームの法則で説明できる
3. 一瞬の電圧の落ちこみを無視して、本当に下がったときだけ知らせるプログラムを作れる
4. 電圧の見はりを、ほかのプログラムに組みこめる

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |
|---|---|---|
| Cell | セル | バッテリーの中の、1 つ 1 つの電池。LiPo は 1 セルが約 3.7 V |
| 2S | 2 セル直列 | セルを 2 つ直列につないだバッテリー。電圧は 2 倍になる |
| Nominal voltage | 公称電圧 | バッテリーのラベルに書かれている、ふつうの電圧 |
| Over-discharge | 過放電 | 電圧が下がりすぎるまで使うこと。LiPo が傷む |
| Internal resistance | 内部抵抗 | バッテリーそのものがもっている、小さな抵抗 |
| Voltage sag | 電圧の落ちこみ | 大きな電流が流れたときに、電圧が一瞬下がること |
| Low-voltage cutoff | 低電圧カット | 電圧が下がったら、モーターを止めるしくみ |
| Latch | ラッチ | 一度そうなったら、もとにもどらないようにすること |

## ③ 本文

### LiPo の電圧の目安

LiPo の電圧は、1 セルあたりで考えます。この回では、RACECAR のバッテリーを 2 セル直列（2S、公称 7.4 V）として書きます。2S なら、バッテリー全体の電圧は、1 セルの電圧の 2 倍です。自分のバッテリーのラベルで、セルの数を確かめましょう（⑤）。

| | 1 セル | 2S のバッテリー全体 |
|---|---|---|
| 満充電 | 4.2 V | 8.4 V |
| 公称電圧 | 3.7 V | 7.4 V |
| しまっておく（保管する）ときの電圧 | 3.8 V | 7.6 V |
| 多くの低電圧カットが働く電圧 | 約 3.2 V | 約 6.4 V |
| これより下げてはいけない | 3.0 V | 6.0 V |

:::message alert
3.0 V は「ここまで使ってよい」電圧ではなく、「これより下げると傷む」電圧です。この回のプログラムは、それよりずっと手前（1 セル 3.4 V）で止まるようにしています。バッテリーの扱い（充電・保管・ふくらんだときの対応）は、かならず先生や大人と確認し、バッテリーの説明書にしたがいましょう。
:::

### 走っているとき、電圧は一瞬下がる

電気の流れにくさを抵抗といい、単位はオーム〔Ω〕です。抵抗 $R$ に電流 $I$ が流れると、その両はしには $V = I \times R$ の電圧がかかります。これを**オームの法則**といいます。

バッテリーには、それ自体に小さな抵抗（内部抵抗）があります。電流 $I$ が流れると、内部抵抗 $r$ にかかる $I \times r$ の分だけ、電圧が下がって見えます。

$$
V_{\text{測る}} = V_{\text{電流なし}} - I \times r
$$

発進や加速のときは、大きな電流が流れるので、電圧がぐっと下がります。図1は、この本で作った説明用の簡単なモデルで、2S のバッテリーを使いきるまで走らせたときの電圧です。6 秒ごとに 1 秒、加速で 20 A 流れるとしました（ふだんは 3 A）。内部抵抗を 0.03 Ω とすると、加速のたびに $20 \times 0.03 = 0.6$ V 下がります（右の拡大）。

電圧が一瞬でも 7.2 V（1 セル 3.6 V）を下回ったら「注意」にすると、138 秒で注意になってしまいます。バッテリーには、まだ半分以上残っています。そこで、この回のプログラムは、**2 秒続けて**下回ったときだけ「低い」と考えます。すると、注意は 428 秒、止まるのは 472 秒になりました。加速の落ちこみ（1 秒）は無視され、電流が流れていないときの電圧（黒い点線）そのものが下がってきたときに知らせます。

### 電圧を見はるクラス

見はる部分は、ほかのプログラムでも使えるように、クラスにまとめます。

```python:battery_guard.py
"""
battery_guard.py
バッテリーの電圧を見はって、「注意」「止まる」を決めるクラス（9-2）。
使い方：
    from battery_guard import BatteryGuard
    guard = BatteryGuard()
    state = guard.update(rc.physics.get_battery_voltage(), rc.get_delta_time())
"""

CELLS = 2              # 直列につないだセルの数（2S のバッテリーなら 2。自分のバッテリーのラベルで確かめる）
WARN_PER_CELL = 3.6    # 1 セルあたりこれより低いと「注意」（V）
STOP_PER_CELL = 3.4    # 1 セルあたりこれより低いと「止まる」（V）。多くの低電圧カット（3.2 V）より余裕をもたせる
HOLD_TIME = 2.0        # この時間（秒）続けて低いときだけ、低いと判断する（加速したときの一瞬の電圧の落ちこみを無視する）

OK, WARN, STOP, NO_SENSOR = "OK", "注意", "止まる", "センサなし"


class BatteryGuard:
    def __init__(self):
        self.state = OK
        self.low_time = {WARN: 0.0, STOP: 0.0}     # それぞれのしきい値より低い時間が、続いている長さ（秒）

    def update(self, voltage, dt):
        """今の電圧（V）と 1 コマの時間（秒）から、状態を返す。一度「止まる」になったら、もどらない"""
        if voltage <= 0.0:                         # シミュレータは 0.0 を返す（電圧のセンサがない）
            return NO_SENSOR
        per_cell = voltage / CELLS
        for level, limit in ((WARN, WARN_PER_CELL), (STOP, STOP_PER_CELL)):
            if per_cell < limit:
                self.low_time[level] += dt
            else:
                self.low_time[level] = 0.0
        if self.low_time[STOP] >= HOLD_TIME:
            self.state = STOP
        elif self.state != STOP and self.low_time[WARN] >= HOLD_TIME:
            self.state = WARN
        return self.state
```

- `update()` を毎コマ呼び、電圧（V）と 1 コマの時間（秒）を渡します。状態（`"OK"`・`"注意"`・`"止まる"`・`"センサなし"`）が返ります
- `low_time` は、「注意」と「止まる」のそれぞれのしきい値より、低い時間が続いている長さです。しきい値より高くなったら、0 にもどします
- 一度「止まる」になったら、「OK」にはもどりません（ラッチ）。走るのをやめると電流が減って、電圧が少し上がる（もどって見える）からです
- シミュレータは電圧が 0.0 なので、`"センサなし"` を返して、何もしません

### 手動運転しながら見はる

次のプログラムは、コントローラーで運転しながら、電圧を見はります。

```python:battery_monitor.py
"""
battery_monitor.py
右トリガーで前へ、左スティックでハンドル（手動運転）。そのあいだ、バッテリーの電圧を見はる（9-2）。
「注意」になったら速さの上限を半分に、「止まる」になったら前へ進まないようにする。
battery_guard.py を同じフォルダに置いて使う。実機専用（シミュレータでは電圧が 0.0 で、見はらない）。
"""

import sys

sys.path.insert(1, "../../library")
import racecar_core
from battery_guard import BatteryGuard, CELLS, WARN, STOP

rc = racecar_core.create_racecar()

MAX_SPEED = 0.5        # トリガーをいっぱいに押したときの speed
guard = BatteryGuard()
state = ""
volts = []             # 1 秒の間の電圧の記録（平均と最小を表示する）


def start():
    rc.drive.set_max_speed(0.25)
    rc.drive.stop()
    print(">> 手動運転しながら、バッテリーの電圧を見はります")


def update():
    global state
    voltage = rc.physics.get_battery_voltage()
    volts.append(voltage)
    new_state = guard.update(voltage, rc.get_delta_time())
    if new_state != state:
        print(f"バッテリー：{new_state}（{voltage:.2f} V）")
        state = new_state

    speed = rc.controller.get_trigger(rc.controller.Trigger.RIGHT) * MAX_SPEED
    angle = rc.controller.get_joystick(rc.controller.Joystick.LEFT)[0]
    if state == WARN:
        speed *= 0.5                   # 注意：ゆっくり走って、もどってくる
    if state == STOP:
        speed = 0.0                    # 止まる：もう前へ進まない
    rc.drive.set_speed_angle(speed, angle)


def update_slow():
    if len(volts) > 0 and max(volts) > 0:
        average = sum(volts) / len(volts)
        print(f"  電圧 平均 {average:.2f} V（1 セル {average / CELLS:.2f} V）　いちばん低い {min(volts):.2f} V　"
              f"電流 {rc.physics.get_battery_current():.1f} A　{state}")
    volts.clear()


if __name__ == "__main__":
    rc.set_start_update(start, update, update_slow)
    rc.go()
```

- 状態が変わったときだけ、`バッテリー：注意（7.17 V）` のように表示します
- 「注意」になったら速さを半分にして、ゆっくりもどってこられるようにします。「止まる」になったら、前へ進みません
- `update_slow()` では、1 秒の間の電圧の平均と、いちばん低い値を表示します。いちばん低い値を見ると、加速でどれだけ下がったかがわかります

### ほかのプログラムに組みこむ

`battery_guard.py` を同じフォルダに置けば、第7章・第8章のプログラムにも組みこめます。たとえば、`grand_prix.py`（8-1）なら、次の3か所を足します。

```python
from battery_guard import BatteryGuard, STOP     # はじめの import に足す

guard = BatteryGuard()                           # 変数を作るところに足す

# update() の最後の set_speed_angle の直前に足す
if guard.update(rc.physics.get_battery_voltage(), rc.get_delta_time()) == STOP:
    speed = 0.0
```

止まったら、コースの外で RB をはなし、プログラムを終えて、バッテリーを外しましょう。

## ④ 数式・コード

### 1 セルあたりの電圧

バッテリー全体の電圧を $V$、セルの数を $N$ とすると、1 セルあたりの電圧は次のとおりです。

$$
V_{\text{セル}} = \frac{V}{N}
$$

`battery_guard.py` の `per_cell = voltage / CELLS` が、この式です。しきい値を 1 セルあたりで書いておくと、セルの数がちがうバッテリーでも、`CELLS` を変えるだけで使えます。

### 止まるしきい値に、余裕をもたせる理由

止まるしきい値を 1 セル 3.4 V にしたのは、加速の落ちこみを考えるためです。図1のモデルでは、「止まる」になったとき、電流が流れていないときの電圧は 1 セル約 3.42 V でした。そこで 20 A 流れると、

$$
3.42 - \frac{20 \times 0.03}{2} = 3.42 - 0.30 = 3.12 \ \text{V}
$$

まで下がります（内部抵抗 0.03 Ω はバッテリー全体の値なので、1 セルあたりは半分）。実際に、止まる前のいちばん低い値は、全体で 6.23 V（1 セル約 3.11 V）でした。しきい値を 3.2 V にしていたら、止まる前に、多くの低電圧カットの電圧や 3.0 V に近づいてしまいます。

## ⑤ つまずきポイント

### セルの数をまちがえる

3 セル（3S、公称 11.1 V）のバッテリーで `CELLS = 2` のままだと、1 セルが 5 V 以上に見えて、いつまでも「OK」のままです。反対に、2S で `CELLS = 3` にすると、はじめから「止まる」になります。自分のバッテリーのラベル（「2S」「7.4V」など）で確かめましょう。

### シミュレータで、何も表示されない

シミュレータの `rc.physics.get_battery_voltage()` は、いつも 0.0 を返します。`battery_guard.py` は 0.0 のとき `"センサなし"` を返すので、状態は変わりません。このプログラムは実機で動かします。

### 止まったあと、電圧がもどったので、また走らせた

走るのをやめると電流が減って、電圧は少し上がります。これは、バッテリーが回復したのではありません。「止まる」になったら、その日の走行は終わりにして、充電しましょう。

### 電圧を見はっていれば、ほかの安全対策は要らない

このプログラムは、プログラムが動いている間しか見はりません。プログラムを終えたあとも、バッテリーをつないだままにしておくと、電圧は少しずつ下がります。使い終わったらバッテリーを外し、充電と保管は、決められた充電器と方法で行いましょう。

## ⑥ 確認問題

**問1**　2S のバッテリーの電圧が 7.0 V でした。1 セルあたりの電圧は何 V ですか。`battery_guard.py` のしきい値では、この電圧が 2 秒続くと、どの状態になりますか。

:::details 答え
$7.0 \div 2 = 3.5$ V です。「注意」（3.6 V）より低く、「止まる」（3.4 V）より高いので、「注意」になります。
:::

**問2**　電流が流れていないときの電圧が 7.4 V、内部抵抗が 0.05 Ω のバッテリーで、30 A 流れたとき、測る電圧は何 V になりますか。

:::details 答え
$7.4 - 30 \times 0.05 = 7.4 - 1.5 = 5.9$ V です。1 セルあたり 2.95 V まで下がって見えます。これが一瞬なら、`HOLD_TIME` のおかげで「止まる」にはなりません。ただ、これだけ下がるバッテリーは、内部抵抗が大きくなっている（古くなっている）おそれがあります。
:::

**問3**　`HOLD_TIME` を 0.01 のようにとても短くすると、図1のモデルでは、何が起きますか。

:::details 答え
加速で電圧が一瞬 7.2 V を下回るたびに「注意」になり、138 秒で「注意」になります（図1の灰色の点線）。「止まる」も、加速の落ちこみで 6.8 V を下回った 372 秒に、早くなってしまいます。1 コマ（約 0.017 秒）でも下回れば、すぐに切りかわるからです。
:::
