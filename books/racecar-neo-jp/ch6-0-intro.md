> ロボットを自動で動かすために使われる、いろいろな制御のしかたを学び、自分でライントレースのプログラムを作りましょう！
>
> ── BWSI オンライン事前コース 第6章の紹介文より

第5章で、車はカメラや LIDAR で、まわりの様子を数として受けとれるようになりました。この章では、その数を使って、**見ながら、ずれを直しながら走る**プログラムを作ります。4-2 で学んだ「クローズドループ（フィードバック）」を、実際に組み立てていきます。

中心になるのは、次の2つです。

- **比例制御（P）から PID 制御へ**：ずれに比例してハンドルを切る、いちばん基本の考え方から始めて、ふらつきを抑える工夫を1つずつ足していきます
- **LIDAR による壁沿い走行**：Lab I の課題を、測り方・直し方の両面から、段階を追って仕上げていきます

## この章の内容

| 回 | タイトル | できるようになること |
|---|---|---|
| 6-1 | 比例制御の考え方 | 目標とのずれに比例して命令を決める、フィードバック制御の基本を説明する |
| 6-2 | ライントレース | カメラで床の線の位置を求め、比例制御で線の上を走る（Lab F） |
| 6-3 | AR マーカーで進む方向を決める | マーカーに近づき、番号に合わせて曲がる向きを変える |
| 6-4 | 壁沿い走行とは | Lab I の課題とシミュレータのコース、これから作るものの全体像を知る |
| 6-5 | LIDAR で壁までの距離を測る | 車が傾いていても、壁までの本当の距離を求める |
| 6-6 | ノイズに強い測り方 | ばらつきや、ぬけ・すき間のあるデータから、安定した距離を求める |
| 6-7 | P：ずれに比例してハンドルを切る | 壁から決まった距離を保って走る、比例制御のプログラムを書く |
| 6-8 | ふらつきを観察する | 比例制御だけでは揺れが止まらない理由を、記録とグラフで調べる |
| 6-9 | D：ずれが縮む速さを見る | ずれの変わる速さを使って、早めにハンドルを戻す |
| 6-10 | 壁の向きを測る | ずれの変わる速さのかわりに、壁の向きを直接測って使う |
| 6-11 | I：いつまでも残るずれを消す | ずれをためた量（積分）を使って、残り続けるずれを消す |
| 6-12 | PID をクラスにまとめる | 時間・出力の上限・積分の暴走（ワインドアップ）の対策をそなえた PID を作る |
| 6-13 | 反応をグラフで評価する | 立ち上がりの時間・行き過ぎの量・落ち着くまでの時間で、制御のよしあしを数で比べる |
| 6-14 | ゲインの決め方 | 手で合わせる手順と、限界感度法でゲインを決める |
| 6-15 | 少し先を見る | 先の壁や正面の壁を見て、曲がり角の手前から曲がりはじめる |
| 6-16 | 両側の壁の真ん中を走る | 左右の壁までの距離の差から、通路の真ん中を走る |
| 6-17 | 状態で切り替える | 右だけ・左だけ・両側・壁なしで、走り方を切りかえる |
| 6-18 | 狭い通路・広い通路・急カーブ | 正面の壁を見て、開いている側へ曲がり、コースを最後まで走る |
| 6-19 | 速度も PID で制御する | 正面の壁までの距離で速さを決め、速さに合わせてハンドルのゲインを変える |
| 6-20 | タイムアタック | 設定を1つずつ変えて何回も走らせ、速さと余裕のかね合いで選ぶ（Lab I） |
| 6-21 | PID を使い回す | 同じ PID クラスで、ライントレースとコーンへの駐車を作り直す |
| 6-22 | ゲインを自動で探す | 走りのよしあしを数で表し、勾配降下法でゲインを調整する |
| 6-23 | 人の運転をまねる | 手動で運転した記録から、ニューラルネットワークに運転を学ばせる |
