5-8 の勾配降下法では、損失の「傾き」をもとに、パラメータを動かしました。パラメータが2つなら、傾きの式を手で導けます。でも、ニューラルネットワークのパラメータは、何百、何百万とあります。この回では、そのすべての傾きを、まとめて効率よく求める**誤差逆伝播**（バックプロパゲーション）を学びます。最後に、5-9 で手で決めた「赤を見分けるネットワーク」の重みを、データから学習させます。

## ① この回でできるようになること

1. 計算を小さな段に分けた「計算グラフ」で、前向きに値を計算できる
2. 連鎖律（外側の傾き × 内側の傾き）を使って、後ろ向きに傾きを求められる
3. 誤差逆伝播で求めた傾きが正しいことを、勾配チェックで確かめられる
4. 小さなニューラルネットワークを、誤差逆伝播と勾配降下法で学習させられる

## ③ 本文

### 計算を段に分ける：計算グラフ

1つのニューロンと損失の計算を、段に分けてみます。入力は $x = 1.0$、重みは $w = 0.5$、バイアスは $b = -0.2$、正解は $y = 1$ とします。

1. かけ算：$w \times x = 0.5$
2. 足し算：$z = 0.5 + b = 0.3$
3. シグモイド関数：$a = \sigma(0.3) \approx 0.574$
4. 損失：$L = (a - y)^2 = (0.574 - 1)^2 \approx 0.181$

このように、計算を小さな段に分けてつないだものを**計算グラフ**といいます。入力から順に値を計算していくことを、**前向きの計算**（順伝播）といいます。

![計算グラフの図。w=0.5 と x=1.0 がかけ算の段に入り、0.5 になる。それと b=−0.2 が足し算の段に入り、z=0.3 になる。シグモイド関数 σ の段を通って a=0.574、損失の段 (a−y)² を通って L=0.181 になる（青い矢印、前向き）。赤い点線の矢印は後ろ向きで、損失の段の傾き ∂L/∂a = 2(a−y) = −0.851、シグモイド関数の傾きをかけて ∂L/∂z = −0.851 × a(1−a) = −0.208、足し算からは ∂L/∂b = −0.208 × 1、かけ算からは ∂L/∂w = −0.208 × x = −0.208 と、傾きをかけながら戻っていく](/images/racecar-neo-jp/5-10/fig1-graph.png)
*図1　1つのニューロンの計算グラフ。青は前向きの値、赤は後ろ向きの傾き*

### 傾きは、段の傾きのかけ算：連鎖律

知りたいのは、損失 $L$ の、$w$ と $b$ についての傾きです。$w$ を少し動かすと、$z$ が動き、$a$ が動き、$L$ が動きます。このように段がつながっているとき、全体の傾きは、**それぞれの段の傾きのかけ算**になります。これを**連鎖律**といいます。

$$
\frac{\partial L}{\partial w}
= \frac{\partial L}{\partial a} \times \frac{\partial a}{\partial z} \times \frac{\partial z}{\partial w}
$$

歯車にたとえると、わかりやすいかもしれません。1つめの歯車が1回転すると2つめが2回転し、2つめが1回転すると3つめが3回転するなら、1つめを1回転させたとき、3つめは $2 \times 3 = 6$ 回転します。

それぞれの段の傾きは、かんたんに求められます。

| 段 | 計算 | その段の傾き | 図1の値 |
|---|---|---|---|
| 損失 | $L = (a - y)^2$ | $\dfrac{\partial L}{\partial a} = 2(a - y)$ | $-0.851$ |
| シグモイド関数 | $a = \sigma(z)$ | $\dfrac{\partial a}{\partial z} = a(1 - a)$ | $0.245$ |
| 足し算 | $z = wx + b$ | $\dfrac{\partial z}{\partial b} = 1$、$\dfrac{\partial z}{\partial w} = x$ | $1$、$1.0$ |

これを、**損失のほうから順に**かけていきます。

1. $\dfrac{\partial L}{\partial a} = -0.851$
2. $\dfrac{\partial L}{\partial z} = -0.851 \times 0.245 \approx -0.208$
3. $\dfrac{\partial L}{\partial b} = -0.208 \times 1 = -0.208$、$\dfrac{\partial L}{\partial w} = -0.208 \times x = -0.208$

このように、損失から入力のほうへ、傾きをかけながら戻っていく計算を、**後ろ向きの計算**（逆伝播）といいます。$w$ を少しだけ動かして求めた傾きも $-0.2081$ で、同じになりました。

### なぜ「後ろ向き」がよいのか

ポイントは、途中の $\frac{\partial L}{\partial z}$ を、$w$ と $b$ の両方で**使い回せる**ことです。大きなネットワークでは、1つの段の先に、たくさんのパラメータがつながっています。後ろから順に計算すれば、途中の結果を1回ずつ計算して使い回せるので、パラメータが何百万個あっても、前向きの計算と同じくらいの手間で、すべての傾きが求まります。

これに対して、5-8 の「少しだけ動かしてみる」方法では、パラメータ1つごとに損失を計算し直す必要があります。パラメータが100万個なら、100万回です。

### 赤を見分けるネットワークを学習させる

5-9 では、赤を見分けるネットワークの重みを、人が決めました。今度は、正解つきのデータから学習させます。

- **かくれ層**：シグモイド関数のニューロン 3 つ（5-9 では2つでしたが、少し余裕を持たせます）
- **出力**：シグモイド関数のニューロン 1 つ。「赤である確からしさ」を 0〜1 で出す
- **損失**：平均二乗誤差（5-7）
- **学び方**：誤差逆伝播で傾きを求め、勾配降下法（5-8）でパラメータを動かす

```python:backprop_red.py
"""
backprop_red.py
色合い H から「赤かどうか」を答えるニューラルネットワークを、誤差逆伝播と勾配降下法で学習させる。
かくれ層はシグモイド関数のニューロン 3 つ、出力もシグモイド関数、損失は平均二乗誤差。
"""

import numpy as np

rng = np.random.default_rng(0)

# 作ったデータ：H と、赤かどうかの正解（赤 = 1）。赤のデータを少し多めに入れておく
h = np.concatenate([rng.uniform(0, 180, 200), rng.uniform(0, 10, 50), rng.uniform(170, 180, 50)])
y = ((h < 10) | (h > 170)).astype(float)
x = (h - 90) / 90                      # 入力を -1〜1 くらいにそろえる

HIDDEN = 3                             # かくれ層のニューロンの数
LR = 5.0                               # 学習率

# パラメータ：はじめは、でたらめな小さい値
W1 = rng.normal(0, 1, HIDDEN)          # 入力 → かくれ層 の重み
b1 = rng.normal(0, 1, HIDDEN)          # かくれ層のバイアス
W2 = rng.normal(0, 1, HIDDEN)          # かくれ層 → 出力 の重み
b2 = 0.0                               # 出力のバイアス


def sigmoid(z):
    return 1 / (1 + np.exp(-z))


for step in range(20001):
    # ---- 前向きの計算（順伝播）----
    z1 = np.outer(x, W1) + b1          # かくれ層の z（データの数 × 3）
    a1 = sigmoid(z1)                   # かくれ層の出力
    z2 = a1 @ W2 + b2                  # 出力の z
    a2 = sigmoid(z2)                   # 出力：赤である確からしさ（0〜1）
    loss = np.mean((a2 - y) ** 2)      # 損失（平均二乗誤差）

    # ---- 後ろ向きの計算（逆伝播）：出力に近いほうから、傾きを順にかけていく ----
    d_a2 = 2 * (a2 - y) / len(x)       # 損失の、a2 についての傾き
    d_z2 = d_a2 * a2 * (1 - a2)        # シグモイド関数の傾き a(1-a) をかける
    d_W2 = a1.T @ d_z2                 # W2 についての傾き
    d_b2 = d_z2.sum()                  # b2 についての傾き
    d_a1 = np.outer(d_z2, W2)          # かくれ層の出力 a1 についての傾き
    d_z1 = d_a1 * a1 * (1 - a1)        # シグモイド関数の傾きをかける
    d_W1 = (d_z1 * x[:, None]).sum(axis=0)   # W1 についての傾き
    d_b1 = d_z1.sum(axis=0)            # b1 についての傾き

    if step in (0, 1000, 5000, 20000):
        print(f"{step:5d} 回め：損失 {loss:.4f}")

    # ---- 勾配降下法（5-8）で、すべてのパラメータを動かす ----
    W1 -= LR * d_W1
    b1 -= LR * d_b1
    W2 -= LR * d_W2
    b2 -= LR * d_b2

# ---- 学習したネットワークを、0〜179 のすべての H で試す ----
h_test = np.arange(180)
a_test = sigmoid(sigmoid(np.outer((h_test - 90) / 90, W1) + b1) @ W2 + b2)
correct = (a_test > 0.5) == ((h_test < 10) | (h_test > 170))
print(f"0〜179 の H で試した正解率：{correct.mean():.1%}")
for hv in (0, 5, 12, 90, 168, 175):
    print(f"  H = {hv:3d} → 赤である確からしさ {a_test[hv]:.2f}")
```

```text
 1000 回め：損失 0.0221
 5000 回め：損失 0.0089
20000 回め：損失 0.0044
0〜179 の H で試した正解率：98.9%
  H =   0 → 赤である確からしさ 1.00
  H =   5 → 赤である確からしさ 1.00
  H =  12 → 赤である確からしさ 0.06
  H =  90 → 赤である確からしさ 0.00
  H = 168 → 赤である確からしさ 0.04
  H = 175 → 赤である確からしさ 1.00
```

はじめはでたらめだった重みが、「赤の両はしで 1、それ以外で 0」を出すように変わりました。まちがえたのは、180個のうち、境目ちょうどの H = 10 と H = 170 の2つだけです。人が「H < 10 または H > 170」というルールを教えたのではなく、**データから**このルールを見つけたことに注目しましょう。

コードの後ろ向きの計算は、図1とまったく同じ形をしています。「損失の傾き → シグモイド関数の傾きをかける → 重みの傾き」を、出力層、かくれ層の順にくり返しているだけです。

### 実際の学習では

5-14 で使う物体検出の学習では、こうした計算を、TensorFlow などのライブラリが自動でやってくれます。ライブラリは、前向きの計算をしながら計算グラフを記録しておき、後ろ向きの計算を自動で組み立てます（**自動微分**）。私たちは、モデルの形と損失を決めるだけで、何百万個ものパラメータの傾きを求められます。

## ④ 数式・コード

### シグモイド関数の傾き

シグモイド関数 $\sigma(z) = \frac{1}{1 + e^{-z}}$ の傾きは、出力 $a = \sigma(z)$ を使って、次のように書けます。

$$
\frac{d\sigma}{dz} = \sigma(z)\,\bigl(1 - \sigma(z)\bigr) = a(1 - a)
$$

前向きの計算で求めた $a$ をそのまま使えるので、後ろ向きの計算がかんたんになります。$a = 0.5$ のとき傾きは最大の $0.25$ で、$a$ が 0 や 1 に近づくほど、傾きは 0 に近づきます。

### 勾配チェック

誤差逆伝播のコードは、1か所まちがえても、それらしく動いてしまうことがあります。そこで、5-8 の「少しだけ動かす」方法で求めた傾きと比べて確かめます。学習を始める前のパラメータで、$W1$ の1つめの重みの傾きを比べると、次のようになりました。

```text
誤差逆伝播で求めた傾き　　：-0.0011571945
少しだけ動かして求めた傾き：-0.0011571962
```

小数第8位までほぼ同じなので、後ろ向きの計算は正しいと考えられます。

### ネットワーク全体の連鎖律

2層のネットワークで、かくれ層の重み $W1$ の傾きは、出力から順に、次のようにかけ算で求めます。

$$
\frac{\partial L}{\partial W1}
= \frac{\partial L}{\partial a_2} \cdot
  \frac{\partial a_2}{\partial z_2} \cdot
  \frac{\partial z_2}{\partial a_1} \cdot
  \frac{\partial a_1}{\partial z_1} \cdot
  \frac{\partial z_1}{\partial W1}
$$

コードの `d_a2 → d_z2 → d_a1 → d_z1 → d_W1` が、この式の左から順のかけ算にあたります。

## ⑤ つまずきポイント

### 損失がほとんど下がらない

シグモイド関数の出力が 0 や 1 にはりついていると、傾き $a(1-a)$ がほとんど 0 になり、学習が進みません。入力の大きさをそろえる（このコードの `x = (h - 90) / 90`）、はじめの重みを小さくする、などが効きます。層が深いネットワークでシグモイド関数より ReLU がよく使われるのも、このためです。

### 学習するたびに、結果が少し変わる

はじめの重みを、でたらめ（乱数）で決めているからです。このコードでは `np.random.default_rng(0)` で乱数の出方を固定しているので、何度実行しても同じ結果になります。0 を別の数に変えると、結果が少し変わります。

### 途中で損失が増えた

学習率が大きすぎる可能性があります（5-8）。学習率を下げて、やり直しましょう。

## ⑥ 確認問題

**問1**　$y = 3u$、$u = 2x$ のとき、$\frac{dy}{dx}$ はいくつですか。連鎖律を使って求めましょう。

:::details 答え
$\frac{dy}{du} = 3$、$\frac{du}{dx} = 2$ なので、$\frac{dy}{dx} = 3 \times 2 = 6$ です。実際、$y = 6x$ なので、傾きは 6 です。
:::

**問2**　図1で、正解が $y = 0$ だったとします。$\frac{\partial L}{\partial a}$ と $\frac{\partial L}{\partial w}$ はいくつになりますか。そのとき、$w$ は増やすべきですか、減らすべきですか。

:::details 答え
$\frac{\partial L}{\partial a} = 2(0.574 - 0) = 1.148$ です。
$\frac{\partial L}{\partial w} = 1.148 \times 0.245 \times 1.0 \approx 0.281$ です。
傾きがプラスなので、勾配降下法では $w$ を**減らし**ます。$w$ を減らすと $z$ と $a$ が小さくなり、正解の 0 に近づきます。
:::

**問3**　パラメータが100万個あるネットワークで、すべての傾きを「少しだけ動かす」方法で求めると、損失を何回計算する必要がありますか。誤差逆伝播なら、どうですか。

:::details 答え
「少しだけ動かす」方法では、もとの損失1回に加えて、パラメータ1つにつき1回ずつ、合わせて約100万回です。
誤差逆伝播なら、前向きに1回、後ろ向きに1回の計算で、100万個すべての傾きが求まります。
:::
