7-7 では、「いちばん広い空き」の「真ん中」をめざしました。でも、選び方はほかにもあります。この回では、**どの空きを選ぶか**と、**空きのどこを狙うか**を、それぞれ2通りずつ試して、くらべます。

## ① この回でできるようになること

1. 空きの選び方（いちばん広い・いちばん遠くまで見える）を、プログラムで切りかえられる
2. 空きの中の狙う所（真ん中・いちばん遠い点）を、プログラムで切りかえられる
3. 4 通りの組み合わせの結果から、真ん中を狙うほうが安全な理由を説明できる

## ③ 本文

### 2つの選び方と、2つの狙い方

**どの空きを選ぶか**

- **いちばん広い空き**（7-7）：ふくまれる点の数がいちばん多い空き
- **いちばん遠くまで見える空き**：空きの中のいちばん遠い点が、いちばん遠い空き。先が長く続いていそうな空きです

**空きのどこを狙うか**

- **真ん中**（7-7）：空きの、左はしと右はしの角度の平均
- **いちばん遠い点**：空きの中で、距離がいちばん大きい点の向き

`gaps.py` に、新しい選び方と狙い方の関数を足します。

```python:gaps.py（つづき）
def deepest_gap(gaps, dists):
    """いちばん遠くまで見える点をふくむ空き"""
    return max(gaps, key=lambda g: dists[g[0]:g[1] + 1].max())


def gap_farthest(gap, angles, dists):
    """空きの中で、いちばん遠い点の角度"""
    i = gap[0] + int(np.argmax(dists[gap[0]:gap[1] + 1]))
    return angles[i]
```

### いちばん遠い点を狙うと

図1の左を見てください。7-7 と同じ場所で、いちばん広い空きの中の「いちばん遠い点」は −24.5° でした。真ん中（−17.8°）より 7° ほど左です。

`front_view()` は 300 cm より遠い値を 300 cm にそろえるので（7-6）、いちばん広い空きの中には、300 cm の点がたくさんあります。`np.argmax()` は、同じ値がいくつもあると、**いちばん前（左）の点**を返します。だから、いちばん遠い点は、300 cm の平らな所の左のはし、つまり**手前にある物のすぐ横**になります。

これは、7-5 の問題と同じです。物のすぐ横をかすめる向きへ進むので、車の幅の分だけ、物にぶつかります。コース B では、スタートしてすぐ、はじめの箱の角にぶつかりました（青）。コース A でも、7-5 と同じ、ななめの通路の出口でぶつかりました。

### いちばん遠くまで見える空きを選ぶと

300 cm の点をふくむ空きが、いくつもできることがあります。`deepest_gap()` は、その中で、いちばん前（左）の空きを選びます。空きの広さは見ないので、**せまくても、遠くまで見えれば選ばれます**。

緑の道すじは、横の通路をぬけて上の通路に入ったあと、急に左へ引き返すように曲がり、曲がり角の内側の角にぶつかりました。ぶつかる 2 秒前、車は上の通路に入った所にいて、2° 以上の広さの空きは、次の3つでした。

| 空き | いちばん遠い点 | どこが見えているか |
|---|---|---|
| −90°〜−70° | 300 cm | 今通ってきた、横の通路の奥 |
| −69°〜−65.5° | 156 cm | 横の通路の、箱のあたり |
| −19°〜+90° | 300 cm | これから進む、上の通路 |

1つめと3つめは、どちらも 300 cm です。`deepest_gap()` は前（左）の、せまい −90°〜−70° を選び、その真ん中の −80° へハンドルを切りました。車は来た道へもどろうとして、角にぶつかったのです。

### 真ん中が安全な理由

空きの真ん中は、空きの左はしと右はしから、いちばん離れた向きです。空きのはしには、たいてい物があります。だから、真ん中を狙えば、両側の物から、なるべく離れて通れます。

広い空きを選ぶのも、同じ理由です。広い空きの真ん中は、はしの物から、角度で大きく離れています。

## ④ 数式・コード

### 同じ値のときに、どれが選ばれるか

Python の `max()` と NumPy の `np.argmax()` は、いちばん大きい値がいくつもあると、**いちばん前のもの**を返します。

```python
import numpy as np
print(np.argmax(np.array([100, 300, 300, 200])))   # 1（2 番ではない）
print(max([(0, 5), (7, 12)], key=lambda g: g[1] - g[0]))   # (0, 5)：どちらも広さ 5 なら、前のほう
```

`front_view()` は左から右の順に並べるので、「前のもの」は「左のもの」です。7-6 の `farthest_front.py` では、これを避けるために、同じ値の中から、いちばん正面に近い点を選びました。

### 真ん中と、はしからの角度

空きのはしの角度を $\theta_s$、$\theta_e$ とすると、真ん中 $\theta_c = (\theta_s + \theta_e)/2$ から、どちらのはしまでも

$$
\theta_c - \theta_s = \theta_e - \theta_c = \frac{\theta_e - \theta_s}{2}
$$

だけ離れています。空きが広いほど、はしの物から離れた向きへ進めます。

### 設定の文字列のつづりをまちがえる

`PICK = "widst"` のようにつづりをまちがえても、エラーになりません。`if PICK == "widest":` が成り立たないので、`else` のほう（いちばん遠くまで見える空き）が選ばれてしまいます。設定を変えたら、走らせる前に、`print(PICK, AIM)` で確かめると安心です。

## ⑥ 確認問題

**問1**　空きが3つ `[(10, 30), (60, 120), (200, 230)]` あり、それぞれの中のいちばん遠い点の距離は、順に 300、180、300 cm でした。`widest_gap()` と `deepest_gap()` は、それぞれどの空きを返しますか。

:::details 答え
`widest_gap()` は、広さが 20、60、30 なので `(60, 120)` を返します。`deepest_gap()` は、300 cm の空きが2つあり、前のほうの `(10, 30)` を返します。
:::

**問2**　いちばん遠い点を狙うと、なぜ物にぶつかりやすいのでしょうか。

:::details 答え
遠い値を 300 cm にそろえているので、いちばん遠い点は、300 cm の所のはし、つまり手前の物のすぐ横になりやすいからです。物のすぐ横をかすめる向きへ進むと、車の幅の分だけ、物にぶつかります。
:::
