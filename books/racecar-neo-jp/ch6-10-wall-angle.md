6-9 の D は、「ずれが変わる速さ」を、過去の記録から計算しました。でも、よく考えると、ずれが変わるのは、車が壁に対して**ななめを向いているから**です。壁のほうを向いていれば近づき、壁から離れる向きなら遠ざかります。それなら、車が壁に対してどちらを向いているかを、LIDAR で**直接測れば**、D と同じ情報が、待たずに手に入るはずです。この回では、2本の光線から壁の向きを測り、D のかわりに使います。

## ① この回でできるようになること

1. 2本の光線の長さから、壁の向きと、壁までの本当の距離を求められる
2. 壁の向きが、ずれの変わる速さと同じ情報をもっている理由を説明できる
3. 距離のずれと壁の向きを使って、壁にそって走るプログラムを書ける
4. D を使う方法と比べて、よい点と、まだ残る弱点を説明できる

## ③ 本文

### いちばん近い点の角度では、ばらつきが大きい

6-5 で、いちばん近い点の角度から、車の傾きがわかることを学びました（傾き ＝ 90 − 角度）。でも、説明用の簡単なモデルで、壁と平行に止まった車で 600 コマ測ると、この傾きは平均 0.0° でしたが、ばらつき（標準偏差）は **5.4°** もあり、−12° から +12.5° まで動きました。

いちばん近い点のまわりには、ほとんど同じ距離の点がたくさんあります（6-6）。どれが「いちばん近い」かは、ばらつきでたまたま決まるので、その角度はあちこちに動いてしまうのです。

### 2本の光線から、壁の向きを求める

そこで、**2本の光線**を使います。真横（90°）の光線の長さを $b$、その 30° 前（60°）の光線の長さを $a$ とします。2本の光線が当たった点 A と B を結んだ線が、壁です。

![2本の光線から、壁の向き α と本当の距離 d を求める図。車は上を向いて進んでいる。右に壁があり、壁は前に行くほど右へ遠ざかるように、少しななめになっている。車から真横（90°）にオレンジの光線 b が出て、壁の点 B に当たる。その 30° 前（60°）に青い光線 a が出て、壁の点 A に当たる。点 B から、車の進む向きと同じ向きの点線を引くと、壁との間の角が α（紫）。車から壁に垂直に引いた緑の点線が、本当の距離 d。左上の囲みに、b：真横の距離 51.1 cm、a：ななめ前の距離 67.3 cm、α：壁の向き 12°、d：本当の距離 ＝ b × cos α ＝ 50 cm とある。左下の囲みには、α ＞ 0 は壁が前に行くほど遠ざかる（車は壁から離れる向きに走っている）、α ＜ 0 は車が壁に近づく向きに走っている、とある](/images/racecar-neo-jp/6-10/fig1-two-rays.png)
*図1　2本の光線から、壁の向き α と本当の距離 d を求める*

車の進む向きと壁の間の角を $\alpha$（アルファ）とすると、三角比を使って、次のように求められます（くわしくは④）。

$$
\alpha = \operatorname{atan2}\left(a \cos 30° - b,\; a \sin 30°\right), \qquad d = b \cos\alpha
$$

- $\alpha > 0$：壁は、前に行くほど遠ざかっている。つまり、車は**壁から離れる向き**に走っていて、距離はこれから増えていく
- $\alpha < 0$：車は**壁に近づく向き**に走っていて、距離はこれから減っていく
- $\alpha = 0$：車は壁と平行

$d$ は、6-5 で求めた「本当の距離」と同じものです。

説明用の簡単なモデルで、壁から 70 cm の所に車を止め、向きを変えて 60 コマずつ測ると、$\alpha$ のばらつきは 1.2〜1.4° でした。いちばん近い点の角度（5.4°）より、ずっと落ち着いています。

### 壁の向きは、ずれの変わる速さと同じ情報

車が速さ $v$ で走っているとき、壁までの距離が1秒あたりに変わる量は、

$$
\text{ずれの変わる速さ} = v \sin\alpha
$$

です。$\alpha > 0$（壁から離れる向き）なら距離は増え、$\alpha < 0$ なら減ります。つまり、**壁の向き $\alpha$ がわかれば、ずれの変わる速さもわかります**。6-9 では、この速さを過去のずれから計算しましたが、今度は LIDAR で、**今の**向きを直接測れます。

そこで、D の部分のかわりに、壁の向きを使います。

$$
\text{angle} = K_P \times \text{error} + K_A \times \alpha
$$

$\alpha > 0$（壁から離れていく）なら、右（壁のほう）にハンドルを切って、離れるのを止めます。$\alpha < 0$ なら、左に切って、近づくのを止めます。6-9 の D と同じブレーキのはたらきです。

### やってみよう：壁の向きを使って走る

```python:wall_follow_angle.py
"""
wall_follow_angle.py
右の壁から TARGET cm の距離を保って走る。
D のかわりに、2本の光線から求めた「壁の向き」を使う。
"""

import sys
import math

sys.path.insert(1, "../../library")
import racecar_core
import racecar_utils as rc_utils

rc = racecar_core.create_racecar()

TARGET = 50.0     # 右の壁から保ちたい距離（cm）
SPEED = 0.5       # 走る速さ（一定）
KP = 0.02         # 距離のずれに対するゲイン
KA = 0.04         # 壁の向き（1°あたり）に対するゲイン
THETA = 30        # 2本の光線の間の角度（度）

distance = None   # 右の壁までの距離（update_slow で表示する）
wall_angle = 0.0  # 壁の向き（度）。＋：壁から離れる向きに走っている
angle = 0.0


def right_wall(scan):
    """右の壁の向き（度）と、壁までの距離（cm）を返す。測れなければ (None, None)"""
    a = rc_utils.get_lidar_average_distance(scan, 90 - THETA)   # ななめ前（60°）の距離
    b = rc_utils.get_lidar_average_distance(scan, 90)           # 真横（90°）の距離
    if a == 0.0 or b == 0.0:
        return None, None
    t = math.radians(THETA)
    alpha = math.atan2(a * math.cos(t) - b, a * math.sin(t))   # 壁の向き（ラジアン）
    return math.degrees(alpha), b * math.cos(alpha)


def start():
    rc.drive.stop()
    print(f">> 右の壁から {TARGET:.0f} cm を保って走ります（距離のずれ ＋ 壁の向き）")


def update():
    global distance, wall_angle, angle

    scan = rc.lidar.get_samples()
    wall_angle, distance = right_wall(scan)

    if distance is None:
        angle = 0.0
    else:
        error = distance - TARGET
        angle = rc_utils.clamp(KP * error + KA * wall_angle, -1.0, 1.0)

    rc.drive.set_speed_angle(SPEED, angle)


def update_slow():
    if distance is None:
        print("壁が見えない")
    else:
        print(f"右の壁まで {distance:5.1f} cm　ずれ {distance - TARGET:+5.1f} cm　壁の向き {wall_angle:+5.1f}°　angle {angle:+.2f}")


if __name__ == "__main__":
    rc.set_start_update(start, update, update_slow)
    rc.go()
```

- `math.atan2(横, 縦)`：「横に進む量」と「縦に進む量」から、角度（ラジアン）を求めます。`math.degrees()` で度に直しています
- 壁の向きは、1回の `scan` だけで求まるので、6-9 のような記録のリスト（`errors`）はいりません

説明用の簡単なモデルで、6-9 と同じく、壁から 100 cm の所から speed 0.5 で走らせると、次のように表示されました。

| P ＋ D（6-9：KP 0.02、KD 0.03） | 49.5〜77.3 cm |

壁の向きを使うほうが、壁にずっと近いまま曲がれました。理由は3つあります。

1. **待たなくてよい**：D は、10コマ前との差から速さを求めるので、少し前の様子しかわかりません。壁の向きは、今の `scan` から、すぐにわかります
2. **ばらつきを増やさない**：D は、小さな時間でわり算をするので、ばらつきが増えます（6-9）。壁の向きは、2つの距離の平均から求めるので、落ち着いています
3. **少し先が見える**：60° の光線は、車の少し前の壁を見ています。壁が曲がり始めると、ずれが変わるより先に、壁の向きが変わります

### まだ残る弱点

モデルで、反対に**左へ** 45° 曲がる壁（壁が車の前に回りこんでくる曲がり方）も試しました。こちらは、どちらの方法でも、曲がり角で壁に 16〜18 cm まで近づきました。右の壁だけを見ていると、前から迫ってくる壁に気づくのが遅れるからです。もっと先を見る方法や、正面の壁も使う方法は、6-11 からあとで扱います。

## ④ 数式・コード

### 壁の向きの式の求め方

車の位置を原点にして、右を $x$、前を $y$ とします。

- 真横の光線が当たった点 B は、$(b,\ 0)$
- 30° 前の光線が当たった点 A は、$(a \cos 30°,\ a \sin 30°)$

壁は、B から A へ向かう線なので、壁にそって「前に $a \sin 30°$ 進むあいだに、右に $a \cos 30° - b$ ずれる」ことになります。前の向きからの角度 $\alpha$ は、

$$
\tan\alpha = \frac{a \cos 30° - b}{a \sin 30°}
$$

を満たす角です。Python では、`math.atan2(横, 縦)` を使うと、わり算をせずに（縦が 0 でも）角度が求まります。

本当の距離 $d$ は、原点から壁までの垂直な距離です。真横の光線 $b$ と、壁に垂直な線の間の角は $\alpha$ なので、$d = b \cos\alpha$ になります。

### KA と KD の関係

ずれの変わる速さは $v \sin\alpha$ でした。$\alpha$ が小さいとき、$\sin\alpha \approx \alpha$（ラジアン）なので、D の部分は、

$$
K_D \times v \sin\alpha \approx K_D \times v \times \frac{\pi}{180} \times \alpha_{\text{度}}
$$

です。説明用の簡単なモデルでは、speed 0.5 のとき $v$ は約 75 cm/秒なので、$K_D = 0.03$ に当たる $K_A$ は、$0.03 \times 75 \times \dfrac{\pi}{180} \approx 0.039$ です。この回の `KA = 0.04` は、この計算から決めました。シミュレータでは、speed と実際の速さの関係がモデルと違うので、KA は走らせながら合わせましょう。

## ⑤ つまずきポイント

### 壁から離れていく

`KA * wall_angle` の符号を逆にすると、離れる向きのときに、もっと離れるほうへハンドルを切ってしまいます。壁と平行な状態から、車を少し左に向けて走らせ、「壁の向き」が＋になり、angle も＋（右）になることを確かめましょう。

### 60° の光線が、すき間の奥を見てしまう

60° の光線の先に、入り口やすき間があると、$a$ が長くなり、「壁から離れる向き」とまちがえてしまいます。6-6 のように、まわりの値を平均したり、いちばん近い点と組み合わせたりする工夫が必要です。

### THETA の決め方

`THETA` を大きくすると（たとえば 45°）、より前の壁を見るので、曲がり角に早く気づけます。でも、光線が長くなるので、ばらつきが大きくなり、曲がった壁や、すき間の影響も受けやすくなります。小さくしすぎると、2つの点が近すぎて、向きのばらつきが大きくなります。

## ⑥ 確認問題

**問1**　右の壁と平行に、壁から 50 cm の所を走っています。60° の光線の長さ $a$ は、およそ何 cm ですか（$\cos 30° \approx 0.866$）。

:::details 答え
$a \cos 30° = b = 50$ になるので、$a = 50 \div 0.866 \approx 57.7$ cm です。
:::

**問2**　$a = 60$ cm、$b = 50$ cm でした。壁の向きは＋と－のどちらですか。車は壁に近づいていますか、離れていますか。

:::details 答え
$a \cos 30° \approx 52.0$ で、$b = 50$ より大きいので、$\alpha$ は＋（約 3.7°）です。車は壁から離れる向きに走っています。
:::

**問3**　問2 のとき、本当の距離 $d$ は約 49.9 cm でした。`TARGET = 50`、`KP = 0.02`、`KA = 0.04` なら、angle はいくつですか。

:::details 答え
$0.02 \times (49.9 - 50) + 0.04 \times 3.7 \approx -0.002 + 0.148 \approx 0.15$ です。ずれはほとんど 0 ですが、壁から離れていく向きなので、少し右に切ります。
:::
