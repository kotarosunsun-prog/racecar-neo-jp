5-6 では、しきい値を全部ためして、いちばんよく当たるものを選びました。この回では、数の大きさを予想する**回帰**を取り上げます。そして、「予想がどれだけ外れているか」を1つの数で表す**損失**を学びます。損失は、5-8 の勾配降下法から 5-14 の物体検出の学習まで、機械学習のすべての土台になります。

## ① この回でできるようになること

1. データに直線を合わせる（回帰する）とは、どういうことかを説明できる
2. 予想と実際の差（誤差）から、平均二乗誤差（損失）を計算できる
3. 損失を使って、どの直線がデータによく合っているかを比べられる

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |
|---|---|---|
| Regression | 回帰 | 入力から、数の大きさを予想すること |
| Linear model | 線形モデル | 直線 $y = wx + b$ で予想するモデル |
| Weight | 重み（w） | 直線の傾き。入力が1増えると、予想がどれだけ増えるか |
| Bias | バイアス（b） | 直線の切片。入力が 0 のときの予想 |
| Error / Residual | 誤差（残差） | 実際の値 − 予想した値 |
| Loss function | 損失関数 | 予想の外れ具合を、1つの数で表す計算 |
| Mean squared error | 平均二乗誤差 | 誤差を2乗して平均したもの。MSE と略す |

5-5 のジャイロの「バイアス」とは、同じ言葉ですが意味が違います。ここでのバイアスは、直線の切片のことです。

## ③ 本文

### アクセルの値と速さ

3-2 で学んだように、`set_speed_angle()` の `speed` は速さそのものではなく、アクセルの踏み込み具合です。では、アクセルを 0.3 にすると、実際には何 m/s で走るのでしょうか。

実機には、タイヤの回転から速さを測るセンサ（エンコーダ、`rc.physics.get_encoder_speed()`）があります。アクセルの値を変えながら速さを測ると、次のようなデータがとれたとします（この回では、作ったデータを使います）。

| アクセル $x$ | 0.10 | 0.15 | 0.20 | 0.25 | 0.30 | 0.35 | 0.40 | 0.45 | 0.50 | 0.55 | 0.60 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 速さ $y$〔m/s〕 | 0.12 | 0.29 | 0.41 | 0.46 | 0.59 | 0.70 | 0.86 | 0.96 | 1.11 | 1.13 | 1.38 |

点はほぼ一直線に並んでいます。そこで、次のような直線で、アクセルから速さを予想することにします。

$$
\hat{y} = w x + b
$$

$\hat{y}$（ワイハット）は「予想した $y$」という意味です。$w$ と $b$ がこのモデルのパラメータで、これをデータに合うように決めるのが、この回と次の回の目標です。直線が決まれば、測っていないアクセルの値の速さも予想できます。逆に、「秒速 1 m で走りたいなら、アクセルはいくつにすればよいか」も計算できます（④）。

### どの直線がよく合っているか

![左は、測ったデータの点と、3本の直線の候補。A は w=2.0, b=0.0 で損失 0.0055、B は w=3.0, b=-0.3 で損失 0.0118、C は w=2.4, b=-0.1 で損失 0.0015。C がいちばん点のそばを通っている。右は、直線 A と、それぞれの点との縦のずれ（誤差）を赤い線で示したもの。このずれを2乗して平均したものが損失](/images/racecar-neo-jp/5-7/fig1-fit.png)
*図1　3本の直線の候補（左）と、直線 A の誤差（右）（作ったデータ）*

図1の左を見ると、C がいちばんよく合っていそうです。でも、「よく合っている」を目で決めるのではなく、**数で**決めたいところです。そこで、1つ1つの点について、実際の値と予想した値の差（**誤差**）を求めます。

$$
e_i = y_i - \hat{y}_i = y_i - (w x_i + b)
$$

$i$ は何番めの点かを表します。図1の右の赤い線が、直線 A の誤差です。

### 損失：誤差を1つの数にまとめる

誤差は点の数だけあります。これを1つの数にまとめたものが**損失**です。よく使われるのは、誤差を2乗して平均した**平均二乗誤差**（MSE）です。

$$
L(w, b) = \frac{1}{n} \sum_{i=1}^{n} e_i^{\,2} = \frac{1}{n} \sum_{i=1}^{n} \bigl( y_i - (w x_i + b) \bigr)^2
$$

$n$ は点の数（ここでは 11）です。$\sum$ は「$i = 1$ から $n$ まで全部足す」という記号です。損失が**小さいほど、直線はデータによく合っています**。

なぜ2乗するのでしょうか。

- 誤差には、プラス（点が直線より上）とマイナス（下）がある。そのまま足すと打ち消し合って、外れているのに 0 に近くなってしまう。2乗すれば、どれもプラスになる
- 2乗すると、大きな外れがより大きく数えられる。大きく外れる予想ほど、重く罰することになる

```python:regression_loss.py
"""
regression_loss.py
アクセルの値 x と、実際の速さ y（m/s）のデータに、直線 y = w x + b を合わせる。
いくつかの直線について、合い具合（損失）を計算して比べる。
"""

import numpy as np

# 作ったデータ：アクセルの値と、そのとき測った速さ（m/s）
x = np.array([0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40, 0.45, 0.50, 0.55, 0.60])
y = np.array([0.12, 0.29, 0.41, 0.46, 0.59, 0.70, 0.86, 0.96, 1.11, 1.13, 1.38])


def predict(w, b):
    """直線 y = w x + b で、それぞれの x の速さを予想する"""
    return w * x + b


def loss(w, b):
    """平均二乗誤差：予想と実際の差を2乗して、平均する"""
    error = y - predict(w, b)
    return np.mean(error ** 2)


for w, b in [(2.0, 0.0), (3.0, -0.3), (2.4, -0.1)]:
    print(f"w = {w}, b = {b:5.2f}  →  損失 {loss(w, b):.5f}")
```

```text
w = 2.0, b =  0.00  →  損失 0.00554
w = 3.0, b = -0.30  →  損失 0.01176
w = 2.4, b = -0.10  →  損失 0.00150
```

NumPy の配列どうしの計算は、1つ1つの要素ごとに行われます。`w * x + b` は11個の予想を、`y - predict(w, b)` は11個の誤差を、まとめて計算しています。

目で見たとおり、C の損失がいちばん小さくなりました。これで「どの直線がよく合っているか」を、数で比べられるようになりました。

### 学習とは「損失をいちばん小さくするパラメータを探すこと」

損失 $L$ は、$w$ と $b$ を決めると1つに決まる**関数**です。だから、**損失関数**とよびます。

すると、「データに合う直線を見つける」ことは、「損失 $L(w, b)$ がいちばん小さくなる $w$ と $b$ を探す」ことだと言いかえられます。5-6 のしきい値のように全部ためすのは、パラメータが2つでもたいへんです。次の 5-8 では、損失が小さくなる方向へ、少しずつパラメータを動かして探します。

## ④ 数式・コード

### 直線を使って、必要なアクセルを求める

直線 $y = wx + b$ が決まれば、速さ $y$ で走るのに必要なアクセルは、式を $x$ について解いて求められます。

$$
x = \frac{y - b}{w}
$$

C の直線（$w = 2.4$、$b = -0.1$）なら、秒速 1 m で走るには $x = (1 - (-0.1)) / 2.4 \approx 0.46$ です。このように、「何を送れば、どうなるか」を表すモデルがあると、ほしい結果から逆算して命令を決められます。

### 答え合わせ：いちばん小さい損失

直線の場合は、損失をいちばん小さくする $w$ と $b$ を、式で直接求める方法（最小二乗法）が知られています。NumPy の `np.polyfit()` がそれを計算してくれます。

```python
w, b = np.polyfit(x, y, 1)                 # 1 は「1次式（直線）」の意味
print(f"w = {w:.3f}, b = {b:.3f}, 損失 = {loss(w, b):.5f}")
```

```text
w = 2.369, b = -0.101, 損失 = 0.00134
```

C（損失 0.00150）より、さらに少し小さい損失になりました。これが、このデータでいちばんよく合う直線です。5-8 では、この答えに、少しずつ近づく方法で、たどりつけるかを確かめます。

### 平均絶対誤差

誤差を2乗するかわりに、絶対値（プラスマイナスをとった大きさ）を平均する方法もあります。

$$
\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |e_i|
$$

平均絶対誤差は、大きな外れを2乗ほど重く数えないので、ときどき大きく外れた点（測りまちがいなど）の影響を受けにくい、という特徴があります。

## ⑤ つまずきポイント

### 誤差をそのまま平均したら、0 に近くなった

プラスの誤差とマイナスの誤差が、打ち消し合っているからです。2乗するか、絶対値をとってから平均しましょう。

### 損失の値が、ほかのデータの損失と比べられない

損失の大きさは、データの単位や大きさで変わります。速さを m/s ではなく cm/s で表せば、誤差は100倍、2乗した損失は10000倍になります。損失は、同じデータの上で、モデルどうしを比べるのに使います。

### 直線では合わないデータもある

点が曲がって並んでいるときは、直線ではうまく合いません。5-2 の「距離と面積」のような関係がその例です。曲線を使うモデルや、5-9 のニューラルネットワークを使います。

## ⑥ 確認問題

**問1**　3つの点 $(x, y) = (1, 3), (2, 5), (3, 6)$ に、直線 $\hat{y} = 2x + 1$ を合わせました。平均二乗誤差はいくつですか。

:::details 答え
予想は 3, 5, 7 なので、誤差は $3 - 3 = 0$、$5 - 5 = 0$、$6 - 7 = -1$ です。
2乗すると 0, 0, 1 で、平均は $\frac{0 + 0 + 1}{3} \approx 0.33$ です。
:::

**問2**　誤差が $+0.2$ と $-0.2$ の2点があります。誤差をそのまま平均した値と、平均二乗誤差を求めましょう。

:::details 答え
そのまま平均すると $\frac{0.2 + (-0.2)}{2} = 0$ で、外れているのに 0 になってしまいます。
平均二乗誤差は $\frac{0.04 + 0.04}{2} = 0.04$ です。
:::

**問3**　直線 $y = 2.37x - 0.10$ を使うと、秒速 0.8 m で走るためのアクセルは、およそいくつですか。

:::details 答え
$x = \frac{0.8 - (-0.10)}{2.37} = \frac{0.9}{2.37} \approx 0.38$ です。
:::
