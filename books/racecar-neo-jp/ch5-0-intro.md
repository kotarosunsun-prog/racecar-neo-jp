> RACECAR のセンサをよく観察し、ロボットがまわりの世界からデータを受け取るしくみを学びましょう！
>
> ── BWSI オンライン事前コース 第5章の紹介文より

第4章の車は、目をつぶったまま、決めておいた命令を実行するだけでした。この章では、車に**目**を持たせます。カメラ、LIDAR、IMU から届く数をどう読みとり、どう意味のある情報に変えるかを学びます。

この章は、前半と後半に分かれています。

- **前半（5-1〜5-5）**：センサで世界を見る。カメラの色、LIDAR の距離、AR マーカー、IMU の傾きと向き
- **後半（5-6〜5-14）**：機械学習。人がルールを書くかわりに、データからルールを学ばせる。最後は、自分で集めた写真で物を見つけるモデルを作り、実機の Edge TPU で動かすまでを扱います

## この章の内容

| 回 | タイトル | できるようになること |
|---|---|---|
| 5-1 | カメラ画像と色の表し方（HSV） | 画像を数の表として扱い、色を HSV で表して、決まった色の部分だけを取り出す |
| 5-2 | 色で信号を見分ける | 色のかたまりの位置と大きさを求め、信号の色に合わせて車を動かす（Lab E） |
| 5-3 | LIDAR スキャンの読み方 | 720個の距離から、決まった向きの距離や、いちばん近い物を求める |
| 5-4 | AR マーカーを見つける | 画像の中の AR マーカーの番号・向き・色・位置を読みとる |
| 5-5 | IMU で傾きと向きを測る | 加速度とジャイロを組み合わせる「相補フィルタ」で、傾きや向きを求める |
| 5-6 | 機械学習とは | ルールを書くかわりに、データから学ぶという考え方を知る |
| 5-7 | 直線をデータに合わせる | データに直線を合わせ、合い具合を「損失」という1つの数で表す |
| 5-8 | 損失を少しずつ下げる | 勾配降下法で、損失が小さくなる方向へ少しずつ進む |
| 5-9 | ニューラルネットワーク | 1つのニューロンから、層を重ねたネットワークへ進む |
| 5-10 | 誤差逆伝播 | 計算グラフを使って、たくさんの重みの勾配をまとめて求める |
| 5-11 | 画像の中の物を見つける | 物体検出の出力（枠・名前・自信）と、その評価のしかたを知る |
| 5-12 | データを集める | ボタンで写真を撮って保存するプログラムを作る |
| 5-13 | 正解を付ける | Label Studio で、写真の中の物に枠と名前を付ける |
| 5-14 | 学習させて、Edge TPU 用に変換する | 物体検出のモデルを学習させ、実機で動く形に変換する |

:::message
