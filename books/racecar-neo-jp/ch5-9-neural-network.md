5-7 と 5-8 では、パラメータが2つ（$w$ と $b$）の直線を学習させました。でも、直線だけでは表せない関係もたくさんあります。この回では、小さな計算の部品（ニューロン）をたくさんつないで、複雑な関係を表す**ニューラルネットワーク**を学びます。5-11 で扱う物体検出のモデルも、この部品を何百万個も組み合わせたものです。

## ① この回でできるようになること

1. 1つのニューロンが、入力に重みをかけて足し、関数に通す計算であることを説明できる
2. ステップ関数・シグモイド関数・ReLU の形と役わりを説明できる
3. ニューロン1つでは見分けられないものが、層を重ねると見分けられる理由を、例で説明できる

## ③ 本文

### 1つのニューロン

![1つのニューロンの図。入力 x1 と x2 と 1 に、それぞれ重み w1、w2、b をかけて足し合わせ、z = w1 x1 + w2 x2 + b を作る。z を活性化関数 f に通したものが出力 a = f(z)。w（重み）と b（バイアス）が、学習で決めるパラメータ](/images/racecar-neo-jp/5-9/fig1-neuron.png)
*図1　1つのニューロン*

1つのニューロンは、次の2段の計算をします。

1. 入力に**重み**をかけて足し、**バイアス**を足す：$z = w_1 x_1 + w_2 x_2 + b$
2. その結果を**活性化関数** $f$ に通す：$a = f(z)$

1段めは、5-7 の直線 $wx + b$ と同じ形です。入力が2つ以上あっても、「それぞれに重みをかけて足す」だけです。重みとバイアスが、学習で決めるパラメータです。

### 活性化関数

![3つの活性化関数のグラフ。ステップ関数は z が 0 より小さいと 0、大きいと 1 に、段になって切りかわる。シグモイド関数は 0 から 1 まで、なめらかな S 字で変わる。ReLU は z が 0 より小さいと 0、大きいと z そのままの、折れ線](/images/racecar-neo-jp/5-9/fig2-activation.png)
*図2　よく使われる活性化関数*

| 関数 | 式 | 特徴 |
|---|---|---|
| ステップ関数 | $z > 0$ なら 1、そうでなければ 0 | 「はい／いいえ」をはっきり答える。パーセプトロンで使われた |
| シグモイド関数 | $\sigma(z) = \dfrac{1}{1 + e^{-z}}$ | 0〜1 の間を、なめらかに変わる。「どれくらい確か」を表すのに向く |
| ReLU | $\max(0, z)$ | マイナスなら 0、プラスならそのまま。計算がかんたんで、深いネットワークでよく使われる |

ステップ関数を使ったニューロン（**パーセプトロン**）は、5-6 のしきい値のモデルと同じです。たとえば、入力が色合い H だけなら、「H がある値より大きい（または小さい）か」しか答えられません。

### ニューロン1つでは、赤を見分けられない

5-1 で学んだように、赤の H は、0 の近くと 179 の近くの**両はし**にあります。赤かどうかを答えるには、「H < 10 **または** H > 170」を調べなければなりません。

ニューロン1つ（しきい値1つ）では、H の目もりを1か所で区切って、片側を「赤」と答えることしかできません。どこで区切っても、両はしの赤を両方とも正しく答えることはできないのです。

### 層を重ねると、見分けられる

そこで、ニューロンを2つ並べた層を間にはさみます。

![赤かどうかを答える小さなニューラルネットワーク。入力層の H から、かくれ層の2つのニューロン n1 と n2 につながる。n1 は重み −1、バイアス 10 で、H < 10 なら 1。n2 は重み 1、バイアス −170 で、H > 170 なら 1。出力層のニューロンは、n1 と n2 に重み 1 ずつをかけ、バイアス −0.5 を足して、どちらかが 1 なら 1 を出す。活性化関数はどれもステップ関数](/images/racecar-neo-jp/5-9/fig3-red-network.png)
*図3　赤かどうかを答えるニューラルネットワーク（重みは手で決めたもの）*

- **n1**：$z = -1 \times H + 10$。H が 10 より小さいとき、$z$ がプラスになって 1 を出す（赤の左はし）
- **n2**：$z = 1 \times H - 170$。H が 170 より大きいとき、1 を出す（赤の右はし）
- **出力**：$z = 1 \times n1 + 1 \times n2 - 0.5$。n1 か n2 のどちらかが 1 なら、$z$ がプラスになって 1 を出す

![H を 0 から 179 まで変えたときの値。n1 は H が 10 より小さいところだけ 1。n2 は H が 170 より大きいところだけ 1。出力の「赤？」は、その両方の区間で 1 になり、あいだは 0](/images/racecar-neo-jp/5-9/fig4-red-output.png)
*図4　かくれ層の2つのニューロンと、出力の値*

かくれ層の2つのニューロンが、それぞれ「赤の片はし」を受け持ち、出力のニューロンがそれをまとめています。1つ1つは単純な「しきい値」でも、**組み合わせる**と、1つではできなかった見分けができるのです。

```python:red_network.py
"""
red_network.py
色合い H から「赤かどうか」を答える、小さなニューラルネットワーク（重みは手で決めたもの）。
赤は H が 0 の近くと 179 の近くの両方にあるので、しきい値1つでは見分けられない。
"""

import numpy as np


def step(z):
    """ステップ関数：0 より大きければ 1、そうでなければ 0"""
    return (z > 0).astype(float)


def red_net(h):
    # 1層め（かくれ層）：2つのニューロン
    n1 = step(-1 * h + 10)      # H が 10 より小さいと 1（赤の左はし）
    n2 = step(1 * h - 170)      # H が 170 より大きいと 1（赤の右はし）
    # 2層め（出力層）：どちらかが 1 なら 1
    out = step(1 * n1 + 1 * n2 - 0.5)
    return n1, n2, out


h = np.array([0, 5, 15, 60, 120, 165, 175, 179])
n1, n2, out = red_net(h)
for i in range(len(h)):
    print(f"H = {h[i]:3d}   n1 = {n1[i]:.0f}   n2 = {n2[i]:.0f}   →   赤？ {out[i]:.0f}")
```

```text
H =   0   n1 = 1   n2 = 0   →   赤？ 1
H =   5   n1 = 1   n2 = 0   →   赤？ 1
H =  15   n1 = 0   n2 = 0   →   赤？ 0
H =  60   n1 = 0   n2 = 0   →   赤？ 0
H = 120   n1 = 0   n2 = 0   →   赤？ 0
H = 165   n1 = 0   n2 = 0   →   赤？ 0
H = 175   n1 = 0   n2 = 1   →   赤？ 1
H = 179   n1 = 0   n2 = 1   →   赤？ 1
```

### 重みを、人が決めない

図3の重みは、人が考えて決めました。ニューラルネットワークの本当の力は、**重みをデータから学習できる**ことにあります。「赤」「赤でない」の正解がついた H のデータを見せて、5-8 の勾配降下法で、重みとバイアスを決めさせるのです。

ただし、ステップ関数には問題があります。ステップ関数のグラフは、段のところ以外はどこも平らで、**傾きが 0** です。5-8 の勾配降下法は、傾きを頼りに進む方向を決めるので、傾きが 0 だと、どちらに動かせばよいかがわかりません。

そこで、学習させるときは、ステップ関数のかわりに、なめらかな**シグモイド関数**や **ReLU** を使います。どちらも、ほとんどの場所で傾きが 0 ではありません。次の 5-10 では、シグモイド関数を使ったネットワークに、赤の見分け方を学習させます。

### 大きなネットワーク

5-11 で使う物体検出のモデルは、層が何十も重なり、パラメータは数百万個あります。一番入力に近い層は、「色の境目」「線の向き」のような単純な形に反応し、奥の層に進むほど、「角」「丸」「コーンの形」のような、複雑な形に反応するようになります。図3の「片はしずつ受け持って、あとでまとめる」を、何段も重ねているのです。層をたくさん重ねたネットワークで学ぶことを、**深層学習**（ディープラーニング）といいます。

## ④ 数式・コード

### 層の計算を、行列でまとめる

かくれ層のニューロンが $m$ 個、入力が $k$ 個あるとき、それぞれのニューロンの計算をまとめると、次のように書けます。

$$
\boldsymbol{z} = W \boldsymbol{x} + \boldsymbol{b}, \qquad \boldsymbol{a} = f(\boldsymbol{z})
$$

$W$ は $m$ 行 $k$ 列の重みの表（行列）、$\boldsymbol{x}$ は入力を並べたもの、$\boldsymbol{b}$ はバイアスを並べたものです。図3のかくれ層なら、次のとおりです。

$$
W = \begin{pmatrix} -1 \\ 1 \end{pmatrix}, \quad
\boldsymbol{x} = \begin{pmatrix} H \end{pmatrix}, \quad
\boldsymbol{b} = \begin{pmatrix} 10 \\ -170 \end{pmatrix}
$$

NumPy では、`z = W @ x + b` のように、`@` で行列のかけ算ができます。層がいくつあっても、「行列をかけて、バイアスを足して、関数に通す」のくり返しです。

### パラメータの数

図3のネットワークのパラメータは、かくれ層が「重み 1 個 ＋ バイアス 1 個」× 2 つで 4 個、出力層が「重み 2 個 ＋ バイアス 1 個」で 3 個、合わせて 7 個です。入力が $k$ 個、ニューロンが $m$ 個の層のパラメータは、$m \times k + m$ 個です。

### シグモイド関数で、ステップ関数に近づける

シグモイド関数の $z$ に大きな数をかけると、段がけわしくなり、ステップ関数に近づきます。

$$
\sigma(10 z) = \frac{1}{1 + e^{-10 z}}
$$

たとえば $z = 0.5$ のとき、$\sigma(z) \approx 0.62$ ですが、$\sigma(10z) \approx 0.99$ です。学習では、重みを大きくしていくことで、はっきりした答えを出せるようになります。

## ⑤ つまずきポイント

### 「かくれ層」は、何がかくれているの？

入力層（データを入れるところ）と出力層（答えが出るところ）は、外から見えます。その間の層は、外からは値が直接見えないので、かくれ層とよびます。特別なしかけがあるわけではありません。

### 活性化関数がないと、どうなる？

活性化関数を通さず、$z = wx + b$ だけを何層重ねても、全体は1本の直線（$z = w'x + b'$ の形）にしかなりません。図3のように、途中で「曲げる」「区切る」はたらきをするのが、活性化関数です。

### ニューロンを増やせば、いくらでも賢くなる？

パラメータが多いほど、複雑な関係を表せます。しかしそのぶん、たくさんのデータが必要になり、少ないデータでは 5-6 の**過学習**を起こしやすくなります。データの量に合った大きさのモデルを選びます。

## ⑥ 確認問題

**問1**　ニューロンの重みが $w_1 = 2$、$w_2 = -1$、バイアスが $b = 0.5$、活性化関数がステップ関数です。入力 $x_1 = 1$、$x_2 = 3$ のとき、出力はいくつですか。

:::details 答え
$z = 2 \times 1 + (-1) \times 3 + 0.5 = -0.5$ です。0 より大きくないので、ステップ関数の出力は 0 です。
:::

**問2**　図3のネットワークに H = 8 と H = 100 を入れると、n1、n2、出力はそれぞれいくつになりますか。

:::details 答え
H = 8：n1 は $-8 + 10 = 2 > 0$ で 1、n2 は $8 - 170 < 0$ で 0、出力は $1 + 0 - 0.5 = 0.5 > 0$ で 1（赤）。
H = 100：n1 は $-100 + 10 < 0$ で 0、n2 は $100 - 170 < 0$ で 0、出力は $-0.5$ で 0（赤ではない）。
:::

**問3**　学習させるネットワークで、ステップ関数ではなくシグモイド関数を使うのはなぜですか。

:::details 答え
ステップ関数は、ほとんどの場所で傾きが 0 なので、勾配降下法で「どちらに動かせばよいか」がわからないからです。シグモイド関数はなめらかで、どこでも傾きが 0 ではないので、勾配降下法で学習できます。
:::
