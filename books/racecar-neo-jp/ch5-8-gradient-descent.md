5-7 で、「データに合う直線を見つける」とは「損失がいちばん小さくなるパラメータを探す」ことだとわかりました。この回では、その探し方の基本である**勾配降下法**を学びます。霧の中で山を下りるとき、足もとの傾きだけを頼りに、低いほうへ一歩ずつ進むのと同じ考え方です。何百万個ものパラメータを持つ物体検出のモデルも、この方法で学習しています。

## ① この回でできるようになること

1. 損失の「傾き（勾配）」から、パラメータをどちらに動かせばよいかを説明できる
2. 傾きを、少しだけ動かしてみる方法と、式の両方で求められる
3. 勾配降下法のプログラムを書き、直線をデータに合わせられる
4. 学習率が小さすぎるとき・大きすぎるときに、何が起きるかを説明できる

## ③ 本文

### 損失の坂を下る

5-7 のデータで、$b$ を $-0.101$ に止めたまま、$w$ だけを変えて損失を計算すると、図1のような谷の形になります。いちばん低い点の $w$ が、求めたい答えです。

![w を横軸、損失を縦軸にしたグラフ。損失は谷の形で、w が約 2.37 のところがいちばん低く、そこでの傾きは 0。w が 1.9 の点では接線の傾きがマイナスで、矢印は w を増やす向き（右）。w が 2.85 の点では傾きがプラスで、矢印は w を減らす向き（左）](/images/racecar-neo-jp/5-8/fig1-slope.png)
*図1　損失の「坂」と、進む向き*

今いる点の**傾き**を見れば、どちらに進めば低くなるかがわかります。

- 傾きが**マイナス**（右下がり）なら、右（$w$ を増やす向き）が下り坂
- 傾きが**プラス**（右上がり）なら、左（$w$ を減らす向き）が下り坂
- 傾きが **0** なら、谷の底にいる

つまり、**傾きと反対の向き**に進めば、損失が下がります。坂が急なほど大きく、ゆるやかなほど小さく進むことにすると、次の式になります。

$$
w_{\text{新}} = w - \eta \times (\text{損失の、} w \text{ についての傾き})
$$

$\eta$（イータ）は**学習率**で、1回にどれだけ進むかを決める小さな数です。$b$ についても同じように動かします。これを何度もくり返すのが、**勾配降下法**です。

### 傾きを求める（その1）：少しだけ動かしてみる

傾きは、「$w$ を少しだけ増やしたら、損失がどれだけ変わったか」で求められます。

$$
\text{傾き} \approx \frac{L(w + h,\ b) - L(w,\ b)}{h}
$$

$h$ は、0.000001 のようなとても小さい数です。坂の上で半歩だけ足を出して、高さがどれだけ変わったかを測るようなものです。

### 傾きを求める（その2）：式で求める

平均二乗誤差の場合、傾きは式で求められます（④で導きます）。$e_i = y_i - (w x_i + b)$ は 5-7 の誤差です。

$$
\frac{\partial L}{\partial w} = -\frac{2}{n} \sum_{i=1}^{n} x_i \, e_i ,
\qquad
\frac{\partial L}{\partial b} = -\frac{2}{n} \sum_{i=1}^{n} e_i
$$

$\frac{\partial L}{\partial w}$ は、「ほかのパラメータ（$b$）は止めて、$w$ だけ動かしたときの $L$ の傾き」を表す記号です（偏微分）。2つの方法で、同じ値になるか確かめてみましょう。はじめの点 $w = 0$、$b = 0$ で計算すると、次のようになりました。

```text
少しだけ動かして求めた傾き：w について -0.6282, b について -1.4564
式で求めた傾き　　　　　　：w について -0.6282, b について -1.4564
```

小数第4位まで同じです。どちらもマイナスなので、$w$ も $b$ も増やす向きが下り坂です。

### 勾配降下法のプログラム

```python:gradient_descent.py
"""
gradient_descent.py
5-7 のデータに、勾配降下法で直線 y = w x + b を合わせる。
"""

import numpy as np

x = np.array([0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40, 0.45, 0.50, 0.55, 0.60])
y = np.array([0.12, 0.29, 0.41, 0.46, 0.59, 0.70, 0.86, 0.96, 1.11, 1.13, 1.38])

LR = 0.5          # 学習率：1回にどれだけ動かすか
w, b = 0.0, 0.0   # はじめの値（どこから始めてもよい）

for step in range(1001):
    error = y - (w * x + b)             # 誤差（11個）
    loss = np.mean(error ** 2)          # 損失（平均二乗誤差）

    grad_w = -2 * np.mean(x * error)    # 損失の、w についての傾き
    grad_b = -2 * np.mean(error)        # 損失の、b についての傾き

    if step in (0, 1, 2, 10, 100, 1000):
        print(f"{step:4d} 回め：w = {w:.3f}, b = {b:6.3f}, 損失 = {loss:.5f}")

    w = w - LR * grad_w                 # 傾きと反対向きに、少し動かす
    b = b - LR * grad_b
```

```text
   0 回め：w = 0.000, b =  0.000, 損失 = 0.67190
   1 回め：w = 0.314, b =  0.728, 損失 = 0.11900
   2 回め：w = 0.327, b =  0.618, 損失 = 0.10561
  10 回め：w = 0.666, b =  0.509, 損失 = 0.07403
 100 回め：w = 2.144, b = -0.020, 損失 = 0.00261
1000 回め：w = 2.369, b = -0.101, 損失 = 0.00134
```

1000回くり返すと、$w = 2.369$、$b = -0.101$、損失 0.00134 になりました。5-7 で `np.polyfit()` が出した答えと同じです。答えの式を知らなくても、**傾きを頼りに一歩ずつ下る**だけで、いちばん低い点にたどりつきました。

### 学習率の決め方

![左は、w を横軸、b を縦軸にした損失の等高線と、スタート (0, 0) からの道すじ。学習率 0.5 の道すじは300回で谷底（w 約 2.37、b 約 −0.10）まで着いているが、学習率 0.05 の道すじは同じ300回で途中までしか進んでいない。右は、くり返した回数と損失のグラフ。学習率 0.5 は150回ほどで下がりきり、0.05 はゆっくりしか下がらない。0.95 は損失がどんどん大きくなり、発散している](/images/racecar-neo-jp/5-8/fig2-paths.png)
*図2　学習率による違い（左：進んだ道すじ、右：損失の変わり方）*

学習率は、自分で決めなければならない大事な数です。

- **小さすぎる**（0.05）：確実に下りますが、1歩が小さいので、なかなか谷底に着きません。300回たっても、損失は 0.03 ほど残っています
- **ちょうどよい**（0.5）：150回ほどで谷底に着きます
- **大きすぎる**（0.95）：1歩が大きすぎて谷を飛びこえ、反対側の、もっと高いところに着いてしまいます。それをくり返すので、損失がどんどん大きくなります（**発散**）

このデータでは、学習率が約 0.89 をこえると発散します。はじめは小さめの値から試し、損失が順調に下がるかを見ながら大きくしていきます。

## ④ 数式・コード

### 傾きの式の導き方（高校の微分を使う）

損失は $L = \frac{1}{n}\sum_i e_i^{\,2}$、誤差は $e_i = y_i - w x_i - b$ です。$e_i^{\,2}$ を $w$ で微分すると、合成関数の微分（「外側の微分 × 内側の微分」）から、

$$
\frac{\partial (e_i^{\,2})}{\partial w} = 2 e_i \times \frac{\partial e_i}{\partial w} = 2 e_i \times (-x_i)
$$

となります。これを $n$ 個平均すると、$\frac{\partial L}{\partial w} = -\frac{2}{n}\sum_i x_i e_i$ です。$b$ については $\frac{\partial e_i}{\partial b} = -1$ なので、$\frac{\partial L}{\partial b} = -\frac{2}{n}\sum_i e_i$ になります。

この「外側の微分 × 内側の微分」を、たくさんの段に重ねて使うのが、5-10 の誤差逆伝播です。

### 傾きを、少しだけ動かして確かめるコード

```python
def loss(w, b):
    return np.mean((y - (w * x + b)) ** 2)

w, b = 0.0, 0.0
h = 0.000001
num_w = (loss(w + h, b) - loss(w, b)) / h
num_b = (loss(w, b + h) - loss(w, b)) / h
print(f"少しだけ動かして求めた傾き：w について {num_w:.4f}, b について {num_b:.4f}")
```

式で求めた傾きが正しいかを確かめるのに、とても役に立つ方法です（**勾配チェック**）。ただし、パラメータの数だけ損失を計算し直す必要があるので、パラメータが多いと時間がかかります。学習そのものには、式で求めた傾きを使います。

### 勾配降下法の式

パラメータをまとめて $\boldsymbol{\theta} = (w, b)$、勾配を $\nabla L$ と書くと、勾配降下法は次の1行で表せます。

$$
\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \eta \, \nabla L(\boldsymbol{\theta})
$$

$\nabla L$（ナブラ L）は、それぞれのパラメータについての傾きを並べたものです。パラメータが何百万個に増えても、この式は同じです。

## ⑤ つまずきポイント

### 損失がどんどん大きくなる（`nan` や `inf` になる）

学習率が大きすぎて、発散しています。学習率を 10分の1 くらいにして、やり直しましょう。`nan` は「数ではない」、`inf` は「無限大」という意味です。

### 損失がなかなか下がらない

学習率が小さすぎるか、くり返しの回数が足りません。損失を表示して、下がり続けているなら回数を増やします。まったく下がらないなら、傾きの式の符号（プラスとマイナス）が逆になっていないか確かめましょう。

### 傾きの符号をまちがえて、坂を上ってしまう

`w = w - LR * grad_w` を `+` にすると、傾きと同じ向き、つまり上り坂に進みます。損失が増えていたら、ここを確かめましょう。④の勾配チェックも役に立ちます。

## ⑥ 確認問題

**問1**　ある点で、損失の $w$ についての傾きが $+0.4$ でした。学習率が 0.5 のとき、$w$ はどちらに、どれだけ動きますか。

:::details 答え
傾きと反対の向き、つまり $w$ を減らす向きに、$0.5 \times 0.4 = 0.2$ だけ動きます。
:::

**問2**　損失 $L(w) = (w - 3)^2$ で、$w = 0$ から学習率 0.25 で勾配降下法を始めます。1回めと2回めのあとの $w$ を求めましょう。傾きは $2(w - 3)$ です。

:::details 答え
1回め：傾きは $2(0 - 3) = -6$ なので、$w = 0 - 0.25 \times (-6) = 1.5$ です。
2回め：傾きは $2(1.5 - 3) = -3$ なので、$w = 1.5 - 0.25 \times (-3) = 2.25$ です。
谷底の 3 に、半分ずつ近づいていきます。
:::

**問3**　問2で、学習率を 1.25 にすると、どうなりますか。1回めのあとの $w$ を求めて考えましょう。

:::details 答え
1回め：$w = 0 - 1.25 \times (-6) = 7.5$ です。谷底の 3 を飛びこえて、スタートより遠い（3 から 4.5 離れた）ところに行ってしまいます。これをくり返すと、どんどん遠ざかり、発散します。
:::
