この回の課題は、オンライン事前コースの **Lab D**「迷路を走る（Driving in Mazes）」です。「何秒間、どの速さで、どちらに曲がるか」という命令をいくつも並べておき、ボタンを押したら、車がそれを順番に実行します。

## ① この回でできるようになること

1. 命令を「時間・速さ・角度」の3つの数で表し、Python のリストに並べられる
2. 並べた命令を先頭から順番に実行するしくみ（キュー）を説明できる
3. 命令の列を組み立て、時間を調整して、車に決まった形を走らせられる

## ③ 本文

### 1つの命令を「時間・速さ・角度」で表す

3-2 では、`speed`（速さ）と `angle`（角度）を毎コマ決めて、車に送りました。この2つに**時間**を加えると、「1.5秒間、速さ 0.5 で、まっすぐ走る」のような、ひとまとまりの命令になります。

Lab D では、1つの命令を次のような3つの数の組で表します。

```python
[1.5, 0.5, 0.0]   # [時間, speed, angle]：1.5秒間、速さ 0.5 で、まっすぐ
[1.3, 0.5, 1.0]   # 1.3秒間、速さ 0.5 で、右いっぱいに曲がる
```

`[ ]` でかこんで値をカンマで区切ったものを、**リスト**といいます。リストの中の値は、`[0]`、`[1]`、`[2]` のように番号（**添字**）をつけて取り出します。番号は **0 から**数えることに気をつけましょう。2-3 で LIDAR の値を `scan[0]` のように取り出したのと同じです。

| 書き方 | 取り出される値 | 意味 |
|---|---|---|
| `step[0]` | 1.5 | 時間（秒） |
| `step[1]` | 0.5 | speed |
| `step[2]` | 0.0 | angle |

（`step = [1.5, 0.5, 0.0]` のとき）

### 命令を並べる：リストのリスト

命令を1つずつ、さらに大きなリストに並べていきます。リストの中にリストが入った形です。

```python
queue = [[1.5, 0.5, 0.0],
         [1.3, 0.5, 1.0]]
```

このとき、`queue[0]` は1つめの命令 `[1.5, 0.5, 0.0]`、`queue[1]` は2つめの命令です。番号を2つ続けると、命令の中の値まで取り出せます。たとえば `queue[0][0]` は「1つめの命令の時間」で 1.5、`queue[1][2]` は「2つめの命令の angle」で 1.0 です。

リストには、次のような操作があります。

| 書き方 | はたらき |
|---|---|
| `queue.append(x)` | `x` をいちばん後ろに加える |
| `queue.pop(0)` | 先頭（0番）を取り除く |
| `queue.clear()` | 中身を全部消して、空にする |
| `len(queue)` | 中に入っている数を調べる |

```python:list_demo.py
queue = []
queue.append([1.5, 0.5, 0.0])
queue.append([1.3, 0.5, 1.0])
print(len(queue))   # 2
print(queue[0])     # [1.5, 0.5, 0.0]
queue.pop(0)
print(queue[0])     # [1.3, 0.5, 1.0]
print(len(queue))   # 1
```

`pop(0)` で先頭を取り除くと、残りが1つずつ前につめられ、2つめだった命令が新しい先頭になります。

### キュー：先に並んだものから順に

お店のレジの行列を思い出してください。新しく来た人は**後ろに並び**、会計は**先頭の人から**進みます。このように「後ろに加え、先頭から取り出す」並び方を**キュー**（待ち行列）といいます。Lab D の変数の名前 `queue` は、この英語から来ています。

- 命令を加えるときは、`append` で後ろに並べる
- 実行するのは、いつも先頭の `queue[0]`
- 先頭の命令が終わったら、`pop(0)` で取り除き、次の命令が先頭になる

### 命令を実行するしくみ

毎コマ、`update()` の中で次のことをします。

1. 先頭の命令の speed と angle で走る
2. 先頭の命令の残り時間から、前のコマからの経過時間 `rc.get_delta_time()` を引く
3. 残り時間が 0 以下になったら、先頭の命令を取り除く（次のコマから、次の命令になる）

命令の最初の数は「時間」ではなく、**残り時間**として毎コマ減っていきます。3-1 で作ったタイマーを、命令ごとに1つずつ持たせたものだと考えるとわかりやすいでしょう。

命令がすべてなくなったら、車は止まります。

#### Part 1：命令を実行する部分を完成させる

原典の `update()` の後半には、次の穴うめがあります。

```python
# If the queue is not empty, follow the current drive instruction
if len(queue) > 0:
    speed = _____
    angle = _____
    queue[_][_] -= rc.get_delta_time()
    if queue[_][_] <= 0:
        queue.pop(0)

# Send speed and angle commands to the RACECAR
rc.drive.set_speed_angle(speed, angle)
```

1行目のコメントは「キューが空でなければ、今の命令にしたがう」という意味です。実行するのはいつも**先頭**の命令です。先頭の命令の何番目に何が入っているかを思い出して、うめてみましょう。

:::details 答えの例（Part 1）
```python
if len(queue) > 0:
    speed = queue[0][1]      # 先頭の命令の speed
    angle = queue[0][2]      # 先頭の命令の angle
    queue[0][0] -= rc.get_delta_time()   # 先頭の命令の残り時間を減らす
    if queue[0][0] <= 0:                 # 残り時間がなくなったら
        queue.pop(0)                     # 先頭を取り除く
```
:::

:::message alert
**訳注：穴うめだけでは、始めた瞬間に止まる**
原典の穴をうめただけで実行すると、Enter を押した直後に次のエラーで止まります。

```text
UnboundLocalError: local variable 'speed' referenced before assignment
```

ボタンを押す前はキューが空なので、`if` の中が実行されず、`speed` と `angle` に何も入らないまま `set_speed_angle(speed, angle)` に進んでしまうからです（Python のバージョンによっては `cannot access local variable 'speed' where it is not associated with a value` と表示されます）。

`if` の**前**に次の2行を加えると直ります。キューが空のときは、止まるという意味になります。

```python
speed = 0
angle = 0
```
:::

#### Part 2〜5：命令の列を組み立てる

Part 2〜5 では、`drive_zigzag()`、`drive_spiral()`、`drive_hallway()`、`drive_maze()` の中に、`queue.append([時間, speed, angle])` で命令を並べます。

:::message
Lab D は自動採点つきの課題なので、この本では、コースごとの具体的な数値（答え）は載せません。そのかわりに、組み立て方の手順と、正方形を走る例を示します。
:::

組み立てるときは、次の順番で進めると迷いにくくなります。

1. **動きを区切る**：コースを上から見て、「まっすぐ」「右に曲がる」「左に曲がる」「止まる」の区間に分け、紙に書き出す
2. **区間ごとに命令を1つ書く**：1つの区間が、1つの `[時間, speed, angle]` になる
3. **速さは一定にしておく**：はじめは speed をどの命令も同じ値にして、長さや曲がる量は**時間だけ**で調整する。変える数が少ないほど、調整が楽になる
4. **先頭から1つずつ合わせる**：前の命令がずれると、そのあとの命令は全部ずれた場所から始まる。1つめの区間がうまくいってから、2つめに進む
5. **最後は止まる**：ゴールの中で止まるまでを命令の列に入れる

Part 4・5 には「定数を作ってから並べる」という指示があります。**定数**は、`STRAIGHT_TIME = 1.5` のように名前をつけておく値で、プログラムの途中では変えません。名前を大文字にするのが Python の習慣です。同じ値を何か所でも使うときに、定数を1か所直すだけで全部が変わるので、調整がぐっと楽になります。

#### 例：正方形を走る

Lab D の関数と同じしくみで、A ボタンを押すと右回り（時計回り）の正方形を走るプログラムを作ってみます。`lab_d` フォルダに `square.py` として保存します。

```python:square.py
"""
square.py
A ボタン（キーボードの 1）を押すと、右回り（時計回り）の正方形を走る
"""

import sys
sys.path.insert(1, "../../library")
import racecar_core

rc = racecar_core.create_racecar()

# 調整する数値（定数）。はじめはこの値から始めて、走らせながら合わせる
SPEED = 0.5           # 走るときの速さ
STRAIGHT_TIME = 1.5   # 1辺をまっすぐ走る時間（秒）
TURN_TIME = 1.3       # 右に90°曲がる時間（秒）

# 命令の列。1つの命令は [残り時間, speed, angle]
queue = []


def drive_square():
    queue.clear()                                  # 前の命令を消してから
    for i in range(4):                             # 辺と角を4回くり返す
        queue.append([STRAIGHT_TIME, SPEED, 0.0])  # まっすぐ
        queue.append([TURN_TIME, SPEED, 1.0])      # 右に曲がる


def start():
    rc.drive.stop()
    queue.clear()
    print(">> A ボタン（キーボードの 1）で正方形を走ります")


def update():
    if rc.controller.was_pressed(rc.controller.Button.A):
        drive_square()
        print(f"命令を {len(queue)} 個ならべました")

    # 命令がないときは止まる
    speed = 0.0
    angle = 0.0

    # 命令があれば、先頭の命令にしたがう
    if len(queue) > 0:
        speed = queue[0][1]
        angle = queue[0][2]
        queue[0][0] -= rc.get_delta_time()
        if queue[0][0] <= 0:
            queue.pop(0)
            print(f"次へ（残りの命令：{len(queue)} 個）")

    rc.drive.set_speed_angle(speed, angle)


if __name__ == "__main__":
    rc.set_start_update(start, update)
    rc.go()
```

`for i in range(4):` は、その下の字下げした部分を4回くり返す書き方です。「まっすぐ」と「右に曲がる」を4回並べるので、命令は全部で8個になります。

```bash
racecar cd
cd lab_d
racecar sim square.py
```

## ④ 数式・コード

### 1つの命令は何コマ続くか

1コマの時間を $\Delta t$、命令の時間を $T$ とすると、その命令が続くコマの数 $n$ は、$T$ を $\Delta t$ で割って、**小数点以下を切り上げた**数になります。

$$
n = \left\lceil \frac{T}{\Delta t} \right\rceil
$$

$\lceil\ \rceil$ は「切り上げ」を表す記号です。1コマが $\frac{1}{60}$ 秒なら、1.5 秒の命令は $1.5 \times 60 = 90$ コマ、1.3 秒の命令は 78 コマ続きます。命令が切り替わるのはコマの区切りだけなので、実際に続く時間は、決めた時間ぴったりか、それより最大で1コマ分だけ長くなります（4-2 で使います）。

### 発展：くり返しの中で少しずつ変える

`for i in range(5):` と書くと、`i` には 0, 1, 2, 3, 4 が順に入ります。この `i` を使うと、くり返すたびに少しずつ違う命令を並べられます。次の例は、まっすぐ走る時間が 1.0、1.3、1.6、1.9、2.2 秒とだんだん長くなり、外に広がっていく渦巻きの形です。

```python
for i in range(5):
    queue.append([1.0 + 0.3 * i, SPEED, 0.0])   # だんだん長くなる直線
    queue.append([TURN_TIME, SPEED, 1.0])       # 右に曲がる
```

## ⑤ つまずきポイント

### `global queue` を書かなくても動くのはなぜ？

1-3 では、「関数の中で外の変数を書き換えるときは `global` が必要」と学びました。これは、`counter = counter + 1` のように、変数に `=` で**新しい値を入れ直す**ときの話です。

`queue.append(...)`、`queue.pop(0)`、`queue.clear()`、`queue[0][0] -= ...` は、どれも変数 `queue` を入れ直すのではなく、**リストの中身**を変えています。そのため `global` がなくても動きます。原典のように `global queue` と書いておいても、問題はありません。

### 壁にぶつかって戻されたあと、おかしな動きをする

ぶつかると車はチェックポイントに戻されますが、プログラムの命令の列は、そのまま続きから実行されます。場所と命令が食い違うので、もう一度ボタンを押して、命令の列を最初からやり直しましょう。

### 命令の順番がおかしい

`queue.append` は後ろに加えるので、**書いた順番が走る順番**です。また、関数の最初の `queue.clear()` を消してしまうと、前に押したボタンの命令が残ったまま、後ろに新しい命令がつながります。

### `IndexError: list index out of range` で止まった

リストにない番号を使うと、このエラーになります。1つの命令は `[0]`〜`[2]` の3つしかないので、`queue[0][3]` はエラーです。また、キューが空のときに `queue[0]` を使ってもエラーになります。`queue[0]` を使うのは、`if len(queue) > 0:` の中だけにしましょう。

## ⑥ 確認問題

**問1**　`queue = [[1.0, 0.5, 0.0], [0.8, 0.5, -1.0], [2.0, -0.3, 0.0]]` のとき、次の値はいくつですか。また、3つめの命令で、車はどう動きますか。
(1) `queue[1][2]`　(2) `queue[2][1]`

:::details 答え
(1) −1.0　(2) −0.3
3つめの命令では、2.0 秒間、ハンドルをまっすぐにしたまま、弱めの力で後ろに進みます。
:::

**問2**　1コマが $\frac{1}{60}$ 秒のとき、`[0.5, 0.5, 0.0]` の命令は何コマ続きますか。`[2.0, 0.5, 0.0]` ではどうですか。

:::details 答え
$0.5 \times 60 = 30$ コマと、$2.0 \times 60 = 120$ コマです。
:::

**問3**　正方形の例を、左回り（反時計回り）にするには、どこを変えればよいですか。また、`TURN_TIME` は右回りのときと同じ値でよいでしょうか。

:::details 答えの例
「右に曲がる」命令の angle を `1.0` から `-1.0` に変えます。
`TURN_TIME` は同じ値から始めてかまいませんが、ぴったり合うとは限りません。実機では、左右で曲がり方にくせがあることが多いからです。左回りでも走らせて、合わせ直しましょう（4-2）。
:::

**問4**　原典の Part 1 を、穴をうめただけで実行すると、`UnboundLocalError` で止まります。なぜですか。

:::details 答え
ボタンを押す前はキューが空なので、`if len(queue) > 0:` の中が実行されません。すると `speed` と `angle` に一度も値が入らないまま、`rc.drive.set_speed_angle(speed, angle)` で使おうとするからです。`if` の前で `speed = 0`、`angle = 0` としておけば直ります。
:::
