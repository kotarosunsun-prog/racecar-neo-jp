7-5 と 7-6 では、いちばん遠い「点」1つをめざしたので、角のすぐ横をかすめる光線にだまされました。この回では、点ではなく、**遠くまで見える向きのまとまり**（空き）を探します。まとまりの真ん中をめざせば、両どなりの物から離れて通れるはずです。

## ① この回でできるようになること

1. しきい値を決めて、LIDAR のデータから「空き」を見つけられる
2. いちばん広い空きの、真ん中の向きへ走れる
3. ばらつきで、小さな空きがたくさんできる理由を説明できる

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |
|---|---|---|
| Gap | 空き | しきい値より遠くまで見える向きが、となり合って続いている所 |

## ③ 本文

### 空きとは

7-6 の `front_view()` でそろえた距離を、左はしから右はしへ順に見ていきます。距離が**しきい値**（150 cm）より大きい点が、となり合って続いている所を、1つの「空き」とよぶことにします。空きは、「その向きに、少なくとも 150 cm は進めそう」な向きのまとまりです。

図1の左は、障害物のある通路（コース B）の途中で見た、正面 ±90° です。灰色の線が距離で、赤い点線がしきい値です。線が点線より上にある所が空き（オレンジ）です。

- −54.0°〜+18.5° に、大きな空きがあります（濃いオレンジ）。正面のななめ左は、300 cm 以上空いています。+13° から右は、右前にある箱が見えて 200 cm ほどになりますが、まだ 150 cm より遠いので、空きにふくまれます
- +18.5°〜+26.5° のあたりは、距離が 150 cm 前後なので、細い空きがいくつもできています（うすい線）
- +26.5°〜+64.0° にも、もう1つの空きがあります

いちばん広い空きの、左はし（−54.0°）と右はし（+18.5°）の真ん中は −17.75°（表示では −17.8°）です。車は、この向きへハンドルを切ります。

### 空きを見つける関数

`gaps.py` に、空きを見つける関数と、空きを選ぶ関数、真ん中を求める関数を書き足します。

```python:gaps.py（つづき）
def find_gaps(dists, threshold):
    """距離が threshold より大きい点が続く区間（空き）を、(はじめの番号, おわりの番号) のリストで返す"""
    gaps = []
    start = None
    for i, d in enumerate(dists):
        if d > threshold and start is None:
            start = i                          # 空きのはじまり
        if d <= threshold and start is not None:
            gaps.append((start, i - 1))        # 空きのおわり
            start = None
    if start is not None:
        gaps.append((start, len(dists) - 1))   # 右はしまで続く空き
    return gaps


def widest_gap(gaps):
    """いちばん幅の広い空き"""
    return max(gaps, key=lambda g: g[1] - g[0])


def gap_center(gap, angles):
    """空きの真ん中の角度"""
    return (angles[gap[0]] + angles[gap[1]]) / 2
```

`find_gaps()` は、配列を左から順に見ていき、

- しきい値より遠い点が来て、まだ空きの中でなければ、そこを「空きのはじまり」として覚えます
- しきい値以下の点が来て、空きの中にいれば、1つ前の点までを1つの空きとして、リストに加えます

最後の点まで空きが続いていたら、そこまでを1つの空きにします。空きは、`(はじめの番号, おわりの番号)` の組で表します。空きの広さは、`おわりの番号 − はじめの番号` でくらべます。

### 空きの真ん中へ走る

```python:gap_follow.py
"""
gap_follow.py
LIDAR で正面 ±90° の「空き」を探し、いちばん広い空きの真ん中へ向かって走る（7-7）。
gaps.py を同じフォルダに置いて使う。
"""

import sys

sys.path.insert(1, "../../library")
import racecar_core
import racecar_utils as rc_utils
from gaps import front_view, find_gaps, widest_gap, gap_center

rc = racecar_core.create_racecar()

SPEED = 0.5          # 走る速さ（一定）
FULL_TURN = 30.0     # 目標の向きがこの角度（度）より横にあったら、ハンドルをいっぱいに切る
THRESHOLD = 150.0    # これより遠くまで見える向きを「空き」とする（cm）

target = 0.0         # 目標の向き（度。右が＋）
gaps = []
view = []            # 正面 ±90° の点の角度（update_slow() の表示に使う）


def start():
    rc.drive.stop()
    print(">> いちばん広い空きの真ん中へ走ります")


def update():
    global target, gaps, view
    angles, dists = front_view(rc.lidar.get_samples())
    view = angles
    gaps = find_gaps(dists, THRESHOLD)
    if len(gaps) == 0:                    # 空きがない：止まる
        rc.drive.stop()
        return
    gap = widest_gap(gaps)
    target = gap_center(gap, angles)
    angle = rc_utils.clamp(target / FULL_TURN, -1.0, 1.0)
    rc.drive.set_speed_angle(SPEED, angle)


def update_slow():
    text = "、".join(f"{view[a]:.0f}°〜{view[b]:.0f}°" for a, b in gaps)
    print(f"空き：{text}　目標の向き {target:+.1f}°")


if __name__ == "__main__":
    rc.set_start_update(start, update, update_slow)
    rc.go()
```

空きが1つもないときは、止まります（7-1 の安全停止と同じ考え方です）。`update_slow()` では、空きを角度で表示します。この `gap_follow.py` には、7-8〜7-11 で設定を少しずつ足していきます（完成版は 7-11 にのせます）。

## ④ 数式・コード

### 空きの真ん中

いちばん広い空きの、はじめの点の角度を $\theta_s$、おわりの点の角度を $\theta_e$ とすると、目標の向きは

$$
\theta_{\text{target}} = \frac{\theta_s + \theta_e}{2}
$$

です。図1では $\theta_s = -54°$、$\theta_e = 18.5°$ なので、$(-54 + 18.5) \div 2 = -17.75°$ です。

### 空きの広さと、通れる幅

空きの広さ（角度）が $\Delta\theta$ で、その向きの距離が $d$ のとき、空きの横の幅は、およそ $d \times \Delta\theta$（$\Delta\theta$ はラジアン）です。たとえば、150 cm 先で 10° の空きは、$150 \times 10 \times \pi / 180 \approx 26$ cm しかありません。広さを角度でくらべると、**近くの広い空きより、遠くのせまい空きのほうが、角度が小さく見える**ことに注意しましょう。

## ⑤ つまずきポイント

### 細い空きが、たくさんできる

表示を見ると、`60°〜60°` のように、1 点だけの空きがいくつもあります。距離がしきい値の近くにあると、LIDAR のばらつきで、150 cm を上回ったり下回ったりするからです。6 秒めのように、14 個も空きができることもあります。（表示では角度を整数に丸めているので、`-56°〜-52°、-52°〜65°` のように、となりの空きのはしが同じ数字に見えることがあります。）

いちばん広い空きを選ぶので、1 点だけの空きが選ばれることは、ほとんどありません。でも、もし「空きの数」を使うプログラムを作るなら、細い空きを取りのぞく（たとえば 5 点より細い空きは数えない）必要があります。

### しきい値を変えると、空きの形が変わる

しきい値を小さくすると、空きは広くなり、つながりやすくなります。大きくすると、空きはせまく、細切れになります。7-9 では、しきい値を 100 cm にするとどうなるかを確かめます。

## ⑥ 確認問題

**問1**　`front_view()` のあとの距離が、左から順に `[120, 200, 210, 140, 180, 190, 175, 100]`（8 点）でした。しきい値 150 cm で `find_gaps()` を使うと、何が返りますか。いちばん広い空きはどれですか。

:::details 答え
`[(1, 2), (4, 6)]` が返ります。広さは、(1, 2) が 2 − 1 = 1、(4, 6) が 6 − 4 = 2 なので、いちばん広い空きは (4, 6) です。
:::

**問2**　空きが −30°〜+10° のとき、目標の向きは何度ですか。`FULL_TURN = 30` なら、angle はいくつですか。

:::details 答え
$(-30 + 10) \div 2 = -10°$ です。angle は $-10 \div 30 \approx -0.33$（少し左）です。
:::
