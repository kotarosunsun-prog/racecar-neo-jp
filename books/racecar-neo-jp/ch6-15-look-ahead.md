6-10 の最後に、右の壁が車の前に回りこんでくるような曲がり方（左へ曲がる通路）では、壁に近づきすぎてしまうことを見ました。車の横ばかり見ていると、前から迫ってくる壁に気づくのが遅れるのです。この回では、**少し先**を見て、早めに曲がりはじめる方法を学びます。6-2 のライントレースで「遠くの床を見ると、カーブに早く気づける」と書いたのと同じ考え方です。

## ① この回でできるようになること

1. 壁の向きを使うことが、「少し先の距離」を使うことと同じだと説明できる
2. 正面の距離を測って、前に壁が迫ってきたら、早めにハンドルを切りはじめられる
3. 正面を見はじめる距離（FRONT_LIMIT）を、曲がれる大きさと速さから考えられる

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |

## ③ 本文

### 壁の向きを使うのは、少し先を見ること

6-10 では、距離のずれと、壁の向きを足してハンドルを決めました。

$$
\text{angle} = K_P \times (d - 50) + K_A \times \alpha
$$

じつは、これは「今の距離」ではなく、「**少し先へ進んだときの距離**」を 50 cm に合わせていることと同じです。車が今の向きのまま $L$ cm 進むと、壁までの距離は、およそ $d + L \sin\alpha$ になります（$\alpha$ が＋なら離れていく）。この「先の距離」に KP をかけると、

$$
K_P \times (d + L \sin\alpha - 50) \approx K_P \times (d - 50) + K_P \, L \, \frac{\pi}{180} \times \alpha_{\text{度}}
$$

となって、6-10 の式と同じ形になります（④）。6-14 で合わせた KP 0.04、壁の向き 0.04 は、**約 57 cm 先**の距離を見ていることになります。

### 前から迫る壁は、横の光線では見えない

ところが、右の壁が車の前に回りこんでくる所では、横（90°）とななめ前（60°）の光線だけでは、前に迫ってくる壁に気づくのが遅れます。説明用の簡単なモデルで、6-14 のゲインのまま走らせると、左へ 45° 曲がる通路では壁から 19 cm まで近づき、左へ 90° 曲がる通路では、正面の壁にぶつかりました（図1の灰色）。

### 正面を見る

そこで、**正面の距離**も測ります。正面 ±10° の窓で、いちばん近い物までの距離を求め、それが `FRONT_LIMIT` より近くなったら、近いほど強く、左へハンドルを切ります。

```python
_, front = rc_utils.get_lidar_closest_point(scan, (350, 10))    # 正面（±10°）でいちばん近い物

if front < FRONT_LIMIT:
    angle -= KF * (FRONT_LIMIT - front)    # 正面の壁が近いほど、左へ切る
```

これは、「正面の壁まで `FRONT_LIMIT`」を目標にした P 制御のようなものです。右の壁にそって走っているので、前に壁が来たら、曲がる向きは左です（右に曲がると、右の壁に突っこむ）。

### やってみよう：正面も見ながら壁にそって走る

6-12 の `wall_follow_pid.py` に、正面を見る部分を足したプログラムです。ゲインは 6-14 で合わせた値にしています。`pid.py` を同じフォルダに置いてください。

```python:wall_follow_ahead.py
"""
wall_follow_ahead.py
右の壁にそって走りながら、正面も見る（6-15）。
正面に壁が近づいてきたら、早めに左へハンドルを切りはじめる。
"""

import sys
import math

sys.path.insert(1, "../../library")
import racecar_core
import racecar_utils as rc_utils
from pid import PID              # 同じフォルダの pid.py から読みこむ

rc = racecar_core.create_racecar()

TARGET = 50.0     # 右の壁から保ちたい距離（cm）
SPEED = 0.5       # 走る速さ（一定）
THETA = 30        # 2本の光線の間の角度（度）
FRONT_LIMIT = 200 # 正面の壁がこれより近いと、左へ切りはじめる（cm）
KF = 0.02         # 正面の壁が 1 cm 近づくごとに、左へ切る量

# ハンドルの PID（6-14 で合わせた値）。kd には「壁の向き（度）」のゲインを入れる
steer_pid = PID(kp=0.04, ki=0.005, kd=0.04, i_zone=20)

distance = None   # 右の壁までの距離（update_slow で表示する）
front = 0.0       # 正面の壁までの距離
angle = 0.0


def right_wall(scan):
    """右の壁の向き（度）と、壁までの距離（cm）を返す。測れなければ (None, None)（6-10）"""
    a = rc_utils.get_lidar_average_distance(scan, 90 - THETA)
    b = rc_utils.get_lidar_average_distance(scan, 90)
    if a == 0.0 or b == 0.0:
        return None, None
    t = math.radians(THETA)
    alpha = math.atan2(a * math.cos(t) - b, a * math.sin(t))
    return math.degrees(alpha), b * math.cos(alpha)


def start():
    rc.drive.stop()
    steer_pid.reset()
    print(f">> 右の壁から {TARGET:.0f} cm を保って走ります（正面も見る）")


def update():
    global distance, front, angle

    scan = rc.lidar.get_samples()
    wall_angle, distance = right_wall(scan)
    _, front = rc_utils.get_lidar_closest_point(scan, (350, 10))    # 正面（±10°）でいちばん近い物

    angle = 0.0
    if distance is not None:
        angle = steer_pid.update(distance - TARGET, rc.get_delta_time(), rate=wall_angle)

    if front < FRONT_LIMIT:
        angle -= KF * (FRONT_LIMIT - front)    # 正面の壁が近いほど、左へ切る
    angle = rc_utils.clamp(angle, -1.0, 1.0)

    rc.drive.set_speed_angle(SPEED, angle)


def update_slow():
    if distance is None:
        print("壁が見えない")
    else:
        print(f"右の壁まで {distance:5.1f} cm　正面の壁まで {front:6.1f} cm　angle {angle:+.2f}")


if __name__ == "__main__":
    rc.set_start_update(start, update, update_slow)
    rc.go()
```

- `angle -= ...` のあとで、もう一度 `clamp()` で −1〜1 におさめています。PID の命令と、正面を見た分を足すと、範囲をこえることがあるからです

説明用の簡単なモデルで、左へ 90° 曲がる通路を走らせると、7秒から 11秒の間に、次のように表示されました。

```text
右の壁まで  50.3 cm　正面の壁まで  186.6 cm　angle -0.32
右の壁まで  59.8 cm　正面の壁まで  120.5 cm　angle -0.59
右の壁まで  71.5 cm　正面の壁まで  108.9 cm　angle -1.00
右の壁まで  56.1 cm　正面の壁まで  207.1 cm　angle +0.14
右の壁まで  49.9 cm　正面の壁まで  234.4 cm　angle -0.01
```

正面の壁が 200 cm より近くなると、angle が－（左）になり、近づくほど大きく左に切っています。曲がり終わって正面が開けると、また右の壁にそって走りはじめました。

### FRONT_LIMIT の決め方

`FRONT_LIMIT` を 150 cm にすると、曲がりはじめるのが遅すぎて、ぶつかりました。`KF` を 0.01 にしても（弱すぎて）ぶつかりました。どのくらい手前から曲がりはじめればよいかは、次のように考えます。

- **車が曲がれる大きさ**：ハンドルをいっぱいに切っても、車は、ある半径（**回転半径**）より小さい円はえがけません。説明用の簡単なモデルの車では、約 82 cm です。90° 曲がるには、少なくとも回転半径くらいの距離が、前に必要です
- **目標の距離**：曲がり終わったとき、正面だった壁から 50 cm 離れていたい
- **反応の遅れと速さ**：正面の壁に気づいてから、ハンドルが切れるまでの間にも、車は進みます。速く走るほど、遠くから見はじめる必要があります

モデルでは、82 cm ＋ 50 cm に、反応の間に進む分を足して、200 cm くらいが必要でした。シミュレータでは、車の回転半径も速さもモデルとちがうので、ゆっくりの SPEED で、`FRONT_LIMIT` を大きめから試して、少しずつ小さくしていきましょう。

## ④ 数式・コード

### 先の距離の式

壁に対して角度 $\alpha$ だけ離れる向きに走っている車が、$L$ 進むと、壁までの距離は $L \sin\alpha$ だけ増えます。だから、$L$ 先の距離は $d + L\sin\alpha$ です。$\alpha$ が小さいときは $\sin\alpha \approx \alpha$（ラジアン）なので、

$$
K_P \, L \sin\alpha \approx K_P \, L \, \frac{\pi}{180} \, \alpha_{\text{度}}
$$

これが 6-10 の $K_A \, \alpha_{\text{度}}$ と同じになるのは、

$$
L = \frac{K_A}{K_P} \times \frac{180}{\pi}
$$

のときです。$K_P = 0.04$、$K_A = 0.04$ なら $L \approx 57$ cm です。KP を変えずに KA を大きくすると、もっと先を見ることになります。ただし、この「先の距離」は、今の壁がまっすぐ続くと思って計算した予想なので、壁が曲がっている所では当たりません。正面を見る方法は、その弱点をおぎなうものです。

### 回転半径

前の車輪と後ろの車輪の間の長さ（ホイールベース）を $W$、ハンドルの最大の角度を $\delta$ とすると、回転半径はおよそ次の式で求められます（アッカーマン・ステアリングの考え方）。

$$
R \approx \frac{W}{\tan\delta}
$$

説明用の簡単なモデルは、$W = 30$ cm、$\delta = 20°$ なので、$R \approx 30 \div 0.364 \approx 82$ cm です。

## ⑤ つまずきポイント

### まっすぐな所でも、左へ曲がってしまう

正面の窓を広くしすぎると、横の壁を「正面の壁」とまちがえます。右の壁から 50 cm の所を走っていると、10° 右の光線は、約 288 cm 先で右の壁に当たります（$50 \div \sin 10° \approx 288$）。窓を ±20° にすると、約 146 cm 先で当たるので、`FRONT_LIMIT` が 200 cm だと、まっすぐな所でも左へ切りはじめてしまいます。窓の広さと `FRONT_LIMIT` は、いっしょに考えましょう。

### 左の壁にそって走るときは、右へ切る

左の壁にそって走っているなら、前に壁が迫ってきたとき、曲がる向きは右です。`angle += KF * (FRONT_LIMIT - front)` にします。どちらに曲がるべきかを、車が自分で決める方法は、6-18 で考えます。

### 正面にあるのが、壁ではないとき

正面に、ほかの車やコーンのような物があっても、このプログラムは「壁」だと思って、左へ曲がります。ぶつかりそうなときに止まる方法は、第7章の安全停止で学びます。

## ⑥ 確認問題

**問1**　KP が 0.02、壁の向きのゲイン KA が 0.04 のとき、何 cm 先を見ていることになりますか。

:::details 答え
$L = 0.04 \div 0.02 \times 180 \div \pi \approx 115$ cm です。
:::

**問2**　`FRONT_LIMIT = 200`、`KF = 0.02` で、正面の壁までが 150 cm のとき、正面を見た分で、angle はいくつ変わりますか。

:::details 答え
$0.02 \times (200 - 150) = 1.0$ なので、angle は 1.0 だけ左（－）に変わります。ハンドルをいっぱいに左へ切る大きさです。
:::

**問3**　速く走るとき、`FRONT_LIMIT` は大きくしますか、小さくしますか。

:::details 答え
大きくします。気づいてからハンドルが切れるまでに進む距離が長くなるので、より遠くから見はじめる必要があります。
:::
