ここから 5-14 までは、自分で見つけたい物（たとえばコーン）を見つける物体検出のモデルを、一から作ります。流れは次のとおりです。

1. **データを集める**：見つけたい物の写真をたくさん撮る（この回）
2. **正解を付ける**：写真の中の物に、枠と名前を付ける（5-13）
3. **学習させて、変換する**：モデルを学習させ、実機の Edge TPU で動く形にする（5-14）

5-6 で学んだように、モデルはデータに入っていることしか学べません。どんな写真を集めるかで、できあがるモデルのよしあしが大きく決まります。

## ① この回でできるようになること

1. ボタンを押すと写真を撮って保存するプログラムを書ける
2. 物体検出の学習に向いた写真の集め方を説明できる
3. 実機で撮った写真を、パソコンにコピーできる

## ② 使う用語

| 英語 | 日本語 | ひとことで言うと |
|---|---|---|
| Dataset | データセット | 学習に使うデータのまとまり。ここでは写真の集まり |
| JPEG | JPEG（ジェイペグ） | 写真を保存するときの形式の1つ。拡張子は `.jpg` |
| Diversity | 多様性（ばらつき） | 明るさ・向き・距離・背景などが、いろいろにそろっていること |
| Duplicate | 重複 | ほとんど同じ写真が、何枚も入っていること |
| Domain gap | ドメインギャップ | 学習に使った写真と、実際に使う場面の写真の、見た目の違い |

## ③ 本文

### 写真を撮るプログラム

次のプログラムは、A ボタンで1枚、B ボタンを押している間は 0.5 秒ごとに、カメラの写真を `dataset/images` というフォルダに保存します。トリガーとスティックで車を動かしながら撮れます。

```python:capture.py
"""
capture.py
カメラの写真を撮って、dataset/images フォルダに JPEG で保存する。
A ボタン（キーボードの 1）：1枚撮る。
B ボタン（キーボードの 2）を押している間：0.5秒ごとに撮り続ける。
トリガーとスティックで車を動かせる。
"""

import sys
import os
import cv2 as cv

sys.path.insert(1, "../../library")
import racecar_core

rc = racecar_core.create_racecar()

SAVE_DIR = "dataset/images"   # 保存するフォルダ
INTERVAL = 0.5                # B を押している間、何秒ごとに撮るか

count = 0      # 次に使うファイルの番号
timer = 0.0    # 続けて撮るときのタイマー


def save_photo():
    """今のカメラの画像を、まだ使っていない番号のファイル名で保存する"""
    global count
    image = rc.camera.get_color_image()
    if image is None:
        print("カメラの画像が届いていません")
        return
    path = os.path.join(SAVE_DIR, f"img_{count:04d}.jpg")
    while os.path.exists(path):          # 前に撮った写真を上書きしないように、番号を進める
        count += 1
        path = os.path.join(SAVE_DIR, f"img_{count:04d}.jpg")
    cv.imwrite(path, image)
    count += 1
    print(f"保存しました：{path}")


def start():
    global timer
    rc.drive.stop()
    os.makedirs(SAVE_DIR, exist_ok=True)     # フォルダがなければ作る
    timer = 0.0
    print(">> A：1枚撮る　B を押している間：0.5秒ごとに撮る")


def update():
    global timer

    # 手動で動かす（3-2 と同じ）
    speed = (rc.controller.get_trigger(rc.controller.Trigger.RIGHT)
             - rc.controller.get_trigger(rc.controller.Trigger.LEFT)) * 0.5
    (x, y) = rc.controller.get_joystick(rc.controller.Joystick.LEFT)
    rc.drive.set_speed_angle(speed, x)

    if rc.controller.was_pressed(rc.controller.Button.A):
        save_photo()

    if rc.controller.is_down(rc.controller.Button.B):
        timer -= rc.get_delta_time()
        if timer <= 0:                       # 0.5秒たつごとに1枚
            save_photo()
            timer = INTERVAL
    else:
        timer = 0.0                          # 次に B を押したら、すぐに1枚撮る


if __name__ == "__main__":
    rc.set_start_update(start, update)
    rc.go()
```

プログラムのポイントは、次の3つです。

- **`cv.imwrite(path, image)`**：画像をファイルに保存する OpenCV の関数です。ファイル名の最後を `.jpg` にすると、JPEG で保存されます
- **`f"img_{count:04d}.jpg"`**：番号を4けたにそろえて、`img_0000.jpg`、`img_0001.jpg`… という名前にします。けたをそろえると、ファイルを名前の順に並べたとき、撮った順になります
- **上書きしない工夫**：プログラムを動かし直すと `count` は 0 に戻ります。そこで、同じ名前のファイルがすでにあれば番号を進めて、前に撮った写真を消さないようにしています

B ボタンで続けて撮る部分は、3-1 の「経過時間を引いていくタイマー」と同じしくみです。

作った画像を渡して試すと、次のようになりました。`img_0001.jpg` はすでにあったので、とばしています。B ボタンを押している間は、0.5 秒ごとに保存されています。

```text
保存しました：dataset/images/img_0000.jpg
保存しました：dataset/images/img_0002.jpg
保存しました：dataset/images/img_0003.jpg
保存しました：dataset/images/img_0004.jpg
保存しました：dataset/images/img_0005.jpg
保存しました：dataset/images/img_0006.jpg
```

### 実機で撮って、パソコンにコピーする

実機で使うモデルを作るなら、写真は**実機のカメラで**撮ります。実機では、`-s` をつけずにプログラムを動かします（`-s` はシミュレータで動かすときのしるしです）。

```bash
python3 capture.py
```

写真は、車の中の `dataset/images` に保存されます。学習はパソコンで行うので、写真をパソコンにコピーします。たとえば、パソコンのターミナルで次のように打ちます。`ユーザー名` と `車のIPアドレス`、フォルダの場所は、自分の車に合わせて変えます。

```bash
scp -r ユーザー名@車のIPアドレス:~/フォルダの場所/dataset ./
```

`scp` は、ネットワークでつながったコンピュータの間でファイルをコピーするコマンドです。`-r` は、フォルダの中身をまるごとコピーするという意味です。

:::message
シミュレータでも、このプログラムで写真を撮れます。ただし、シミュレータの画像は実機のカメラの画像とは見た目が違うので（**ドメインギャップ**）、シミュレータの写真だけで学習したモデルは、実機ではうまく見つけられないことが多いです。実機で使うモデルには、実機で撮った写真を使いましょう。
:::

### よいデータセットを作るコツ

モデルは、写真に写っている条件の中でしか、うまく見つけられません。**実際に車を走らせる場面**を思いうかべて、その中のいろいろな条件で撮ります。

| 変えるもの | 例 |
|---|---|
| 距離 | 近く（大きく写る）から、遠く（小さく写る）まで |
| 向き・位置 | 画面の左・右・真ん中、ななめから |
| 明るさ | 明るい場所、暗い場所、窓の光が入る場所 |
| 背景 | 床の色、壁、ほかの物がある場所 |
| 数と重なり | 1つだけ、いくつも、ほかの物に一部かくれている |

ほかにも、次のことに気をつけましょう。

- **ほとんど同じ写真を大量に撮らない**：止まったまま連続で撮ると、同じような写真ばかりになります。B ボタンで撮るときは、車を動かしながら撮ります。`capture.py` が 0.5 秒ごとにしているのも、そのためです
- **必ず見つけたい物が写っている写真にする**：5-14 で使う学習の手順では、正解の枠が1つもない写真があると、途中でエラーになります（5-14 の⑤）。物が写っていない写真は、あとで取りのぞきます
- **種類の数をそろえる**：コーンと人の両方を見つけたいなら、どちらの写真もだいたい同じくらいの数にします。少ない種類は、見つけにくいモデルになります
- **枚数の目安**：多いほどよいですが、はじめは1つの種類につき 100〜200 枚くらいから始めて、うまく見つけられない場面の写真を足していくのが現実的です。5-14 では、全体の 20% ずつを検証用とテスト用に分けるので、学習に使えるのは 60% です

## ④ 数式・コード

### フォルダの中の写真を数える

撮った写真が何枚あるかは、次のように調べられます。

```python
import os

files = [f for f in os.listdir("dataset/images") if f.endswith(".jpg")]
print(f"{len(files)} 枚")
```

`os.listdir()` はフォルダの中のファイル名の一覧を返し、`f.endswith(".jpg")` は名前が `.jpg` で終わるかを調べます。5-14 の学習の手順も、同じように `.jpg` で終わるファイルだけを写真として読みます。

### 必要な容量の目安

横 640 × 縦 480 のカラー画像は、そのままだと $640 \times 480 \times 3 = 921{,}600$ バイト（約 0.9 MB）です。JPEG は写真を圧縮して保存するので、1枚あたりはこれよりずっと小さくなります（写っている物によって変わります）。1000枚撮っても、ふつうは数百 MB 以下です。

## ⑤ つまずきポイント

### `cv.imwrite()` が保存してくれない

`cv.imwrite()` は、保存するフォルダが存在しないと、エラーで止まらずに `False` を返すだけで、何も保存しません。`capture.py` では、`start()` の `os.makedirs()` で、先にフォルダを作っています。なお、ファイル名の最後に `.jpg` などの拡張子がないと、今度は `could not find a writer for the specified extension` というエラーで止まります。

### 写真の拡張子が `.png` や `.JPG` になっている

5-14 で使う学習の手順は、名前が小文字の `.jpg` で終わるファイルだけを写真として読みます。ほかのカメラで撮った写真を加えるときは、拡張子をそろえましょう。

### 写真がどこに保存されたかわからない

`dataset/images` は、プログラムを動かしたときの「今いるフォルダ」の中に作られます。ターミナルで `pwd`（今いるフォルダを表示するコマンド）を打って確かめましょう。

## ⑥ 確認問題

**問1**　`capture.py` で B ボタンを 3 秒間押し続けると、およそ何枚の写真が保存されますか。

:::details 答え
押した瞬間に1枚、そのあと 0.5 秒ごとに1枚ずつなので、$1 + 3 \div 0.5 = 7$ 枚くらいです。
:::

**問2**　コーンを見つけるモデルを作るために、明るい教室の床の上で、コーンを真正面の同じ距離から 200 枚撮りました。このデータセットの問題点を2つ答えましょう。

:::details 答えの例
(1) 距離も向きも同じで、ほとんど同じ写真ばかりになっている。
(2) 明るさや背景が1種類しかないので、暗い場所やほかの床ではうまく見つけられないおそれがある。
ほかに、コーンが1つだけの写真しかない、ほかの物に一部かくれた写真がない、なども考えられます。
:::

**問3**　200 枚の写真のうち、20% を検証用、20% をテスト用に分けると、学習用は何枚になりますか。

:::details 答え
$200 \times (1 - 0.2 - 0.2) = 120$ 枚です。
:::
