第6章では、PID を使って、壁から決まった距離を保ったり、曲がり角を曲がったりしながら走りました。第7章では、次の3つを学びます。

- **ぶつからない工夫**：何をしていても、前に物が近づいたら止まる「安全停止」
- **ステートマシン**：「探す」「近づく」「止まる」のように、場面ごとに走り方を切りかえるプログラムの組み立て方。コーンへの駐車（Lab G）とコーンスラロームで使います
- **いちばん空いている方向へ走る（Gap Follower）**：LIDAR で前の「空き」を探して、そこへ向かう走り方。壁がない所や、障害物がある所でも走れます

最後に、第6章の壁沿い走行と Gap Follower をくらべ、2つを組み合わせます。

## この章の内容

| 回 | タイトル | できるようになること |
|---|---|---|
| 7-1 | LIDAR で衝突を防ぐ（安全停止） | 車の前の帯の中の物までの距離から、速さに合わせてブレーキをかける |
| 7-2 | ステートマシンの設計 | 状態・切りかわる条件・入るときの処理を決めて、プログラムを組み立てる |
| 7-3 | コーンを見つけて駐車する | 探す・近づく・合わせる・止まるの4つの状態で、コーンの 30 cm 手前に止まる（Lab G） |
| 7-4 | コーンスラローム | コーンの色で通る側を決め、次々にコーンの横をぬける |
| 7-5 | いちばん遠い点に向かう | いちばん遠い点へ向かう方法と、その弱点を知る |
| 7-6 | 見る範囲を決める | 正面だけを見て、測れなかった値や遠すぎる値をそろえる |
| 7-7 | 「空き」を見つける | しきい値より遠くまで見える向きのまとまりを見つけ、その真ん中へ走る |
| 7-8 | どの空きの、どこを狙うか | 空きの選び方と、空きの中のどこを狙うかをくらべる |
| 7-9 | 車の幅を考える | いちばん近い物のまわりをふさいで、物から離れて通る |
| 7-10 | 距離が急に変わる場所に注意 | 物のはしで、近い距離を車の幅の分だけのばして、角をこすらないようにする |
| 7-11 | 空き具合でスピードを決める | 前が空いているほど速く走り、ゴールまでの時間をちぢめる |
| 7-12 | 壁沿い走行と比べる | コースの種類ごとに、得意・苦手をくらべる |
| 7-13 | 2つを組み合わせる | 前に物があるかどうかで、壁沿い走行と Gap Follower を切りかえる |
